# Osaider 游戏 Intro：施工顺序与总索引

本套文档用于在 Unreal Engine 5.6 中制作 Osaider 的游戏 Intro 页面。

最终目标是：

> 游戏启动后先进入一个独立的 Intro 关卡。全屏背景循环播放 MP4，玩家点击 `Start` 后，界面淡出并进入现有游戏关卡 `Prototype_07`。

本方案采用 Blueprint-first，不修改现有模块机关、Dice Check、HoverTrace 或相机逻辑。

## 开始前的重要约定

1. Intro 使用独立关卡 `L_Intro`，不直接覆盖在 `Prototype_07` 上。
2. Intro 使用独立的 `BP_IntroPlayerController`，不把启动逻辑写入 `BP_NoCharacterPlayerController`。
3. 视频使用 Unreal Media Framework：`File Media Source → Media Player → Media Texture → UMG Image`。
4. 正式打包的视频必须放在 `Content/Movies` 中；其他目录中的本地文件不会自动进入 Build。
5. 视频打开是异步过程。必须在绑定 `OnMediaOpened` 后再调用 `Open Source`。
6. 视频加载失败时，页面仍必须保留静态背景和可用的 Start 按钮。
7. Start 只允许触发一次，防止快速双击造成重复切关。
8. 红色与蓝色只作为叙事暗示。Intro 仍以深海军蓝、烟熏玻璃和黄铜交互色为主。
9. 文档中的 Content 路径是建议路径；如果实际 UE 项目已有目录规范，可以调整路径，但建议保留资源名称。
10. Intro 复用项目现有的 `WBP_MouseCursor`、`WBP_InvisibleSystemCursor` 和 `E_CursorState`，不要另外制作一套系统鼠标。
11. Intro 使用 `Set Input Mode Game and UI`，不要使用旧方案中的 `UI Only`，以保证自定义鼠标的位置更新、Hover 和按钮点击都正常。

## 推荐资源目录

在 Unreal 项目的 Content Browser 中建立：

```text
Content/Osaider/Intro/
├─ Blueprints/
├─ Maps/
├─ Media/
├─ Textures/
└─ UI/

Content/Movies/Intro/
└─ Osaider_Intro_Loop.mp4
```

建议资源名称：

```text
L_Intro
GM_Intro
BP_IntroPlayerController
WBP_GameIntro
FMS_Intro_Default
MP_Intro
MT_Intro
T_Intro_Fallback
```

## 总体运行流程

```text
启动游戏
→ 打开 L_Intro
→ GM_Intro 使用 BP_IntroPlayerController
→ PlayerController 创建 WBP_GameIntro
→ PlayerController 创建现有 WBP_MouseCursor
→ Set Input Mode Game and UI
→ Widget 绑定 Media Player 回调
→ Open Source(FMS_Intro_Default)
→ OnMediaOpened
→ Set Looping(true)
→ Play
→ 玩家点击 Start
→ 禁止重复点击
→ 播放界面淡出
→ Close Media Player
→ Widget 广播 OnIntroFinished
→ BP_IntroPlayerController 打开 Prototype_07
→ 现有游戏 GameMode 和 BP_NoCharacterPlayerController 接管
```

## 推荐施工节奏

1. 完成 01–02：视频能在 Media Player 编辑器中播放。
2. 完成 03：运行 `L_Intro` 时能显示一个临时 Widget，并且鼠标可用。
3. 完成 04：Intro 页面布局完整，静态回退背景可见。
4. 完成 05：视频能从静态背景平稳切入，并连续循环。
5. 完成 06：Start 淡出后只进入一次 `Prototype_07`。
6. 完成 07：设置默认启动关卡并完成一次独立 Build。
7. 完成 08：在目标机器、目标分辨率和 Shipping Build 中验收。

## 第一版完成标准

- [ ] 游戏启动后进入 `L_Intro`。
- [ ] MP4 全屏播放并保持正确宽高比。
- [ ] 视频结束后无明显停顿地重新循环。
- [ ] 视频加载期间不出现长时间纯黑画面。
- [ ] 视频读取失败时仍能看到静态背景并点击 Start。
- [ ] Start 只触发一次，并带有机械式淡出反馈。
- [ ] 进入 `Prototype_07` 后，HoverTrace、LMB、RMB 和 Space 输入正常。
- [ ] 打包版本中 Intro 关卡、游戏关卡和 MP4 均存在。
- [ ] Intro 逻辑没有写入现有模块 Blueprint。
