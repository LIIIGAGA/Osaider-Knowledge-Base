## 3. Intro Player Controller 的运行顺序

`BP_IntroPlayerController` 的 `BeginPlay` 使用以下顺序：

```text
Event BeginPlay
→ Create WBP_GameIntro
→ 保存为 IntroWidgetRef
→ Add to Viewport，ZOrder = 100
→ Create WBP_MouseCursor
→ 保存为 MouseCursorRef
→ Add to Viewport，ZOrder = 9999
→ 将 MouseCursorRef 设为 Not Hit-Testable (Self & All Children)
→ Set Alignment in Viewport = (0, 0)
→ SetCursorState(Normal)
→ Set Input Mode Game and UI
→ ApplyIntroCustomCursorMode
→ Bind Event to OnIntroFinished
```

`Set Input Mode Game and UI`：

```text
Player Controller = Self
In Widget to Focus = IntroWidgetRef
Mouse Lock Mode = Do Not Lock
Hide Cursor During Capture = false
```

## 4. 自定义鼠标设置

`ApplyIntroCustomCursorMode` 统一执行：

```text
Show Mouse Cursor = true
Enable Click Events = true
Enable Mouse Over Events = true
Current Mouse Cursor = None
```

其中 `Current Mouse Cursor = None` 用来隐藏 UE 默认系统鼠标，只保留 `WBP_MouseCursor`。

鼠标 Widget 每帧更新位置：

```text
Get Mouse Position Scaled by DPI
→ Set Position in Viewport
    Target = MouseCursorRef
    Remove DPI Scale = false
```

注意：

- `WBP_MouseCursor` 的 ZOrder 可以高于 Intro UI；
- 但它必须是 `Not Hit-Testable (Self & All Children)`；
- 因此鼠标图像只负责显示，不会挡住下面的按钮。

## 5. 本次点击问题的真实原因

本次 `START` 按钮不能点击，不是视频、ZOrder 或按钮事件的问题。

真实原因是：

```text
Canvas_Content = Not Hit-Testable (Self & All Children)
```

该选项会让 `Canvas_Content` 以及它下面的所有子控件都不参与命中测试，因此它内部的 `BTN_Start` 也无法收到 Hover 和 Click。

正确设置为：

```text
Canvas_Content = Not Hit-Testable (Self Only)
```

两种设置的区别：

| Visibility 选项 | 作用 |
|---|---|
| `Not Hit-Testable (Self Only)` | 当前容器本身不接收鼠标，但允许子控件接收；适合包着按钮的 Canvas、Safe Zone 等容器 |
| `Not Hit-Testable (Self & All Children)` | 当前控件和全部子控件都不接收鼠标；只适合纯展示、且内部没有交互控件的分支 |

当前已验证的命中设置：

| 控件 | Visibility / Hit Test |
|---|---|
| `Canvas_Root` | `Not Hit-Testable (Self Only)` |
| `IMG_Fallback` | `Not Hit-Testable (Self Only)` |
| `SBOX_VideoCrop` | `Not Hit-Testable (Self Only)` |
| `IMG_Video` | `Not Hit-Testable (Self Only)` |
| `Border_DarkOverlay` | `Not Hit-Testable (Self & All Children)` |
| `SafeZone_Content` | `Not Hit-Testable (Self Only)` |
| `Canvas_Content` | **`Not Hit-Testable (Self Only)`** |
| `TXT_Title` | `Not Hit-Testable` |
| `BTN_Start` | `Visible`，并保持 Enabled |
| `TXT_Start` | `Not Hit-Testable` |
| `TXT_LoadState` | `Not Hit-Testable` |
| `Border_Fade` | `Not Hit-Testable (Self & All Children)` |
| `WBP_MouseCursor` | `Not Hit-Testable (Self & All Children)` |

核心规则：只要一个容器内部还存在按钮，就不要把这个容器设成 `Self & All Children`。

## 6. Start 按钮和关卡跳转

`WBP_GameIntro`：

```text
OnClicked(BTN_Start)
→ Do Once
→ Set Is Enabled(BTN_Start, false)
→ Play Animation(ANIM_IntroExit)
```

退出动画完成后：

```text
Event On Animation Finished
→ 判断 Animation == ANIM_IntroExit
→ Close(Intro Media Player)
→ Call OnIntroFinished
```

`BP_IntroPlayerController` 在创建完 `IntroWidgetRef` 后绑定：

```text
Bind Event to OnIntroFinished
    Target = IntroWidgetRef
    Event = HandleIntroFinished
```

处理事件：

```text
HandleIntroFinished
→ Open Level (by Name)
    Level Name = Prototype_07
```

## 7. 视频与音频基线

当前 Intro 使用：

```text
MP4 → File Media Source → Media Player → Media Texture → UI Material → IMG_Video
```

视频成功打开后：

```text
Set Looping(true)
→ Play
```

当前版本不创建以下内容：

```text
Media Sound Component
BP_IntroMediaAudio
Intro BGM
按钮点击音效
音频淡出逻辑
```

因此测试时，Intro 无声音属于正常表现。不要为了消除“无声音”而额外添加 Media Sound Component，除非以后明确决定为 Intro 制作声音。
