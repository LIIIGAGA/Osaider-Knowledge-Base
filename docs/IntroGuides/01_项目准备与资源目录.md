# 第 01 部分：项目准备与资源目录

## 本部分目标

确认 Intro 的技术边界，创建资源目录，准备第一版 MP4 与静态回退图。本部分结束时不要求视频已经播放，但所有资源应有明确路径和命名。

## 1. 确认当前项目基准

当前项目基准：

```text
Engine = Unreal Engine 5.6
Implementation = Blueprint-first
Gameplay Level = Prototype_07
Gameplay PlayerController = BP_NoCharacterPlayerController
```

Intro 不应修改以下系统：

- `BP_NoCharacterPlayerController` 中的 HoverTrace；
- LMB 点击与拖动路由；
- RMB 模块相机移动；
- Space 全局结构旋转；
- Inventory、Submission 和 Dice Check；
- 模块隐藏与 Reveal 流程。

Intro 结束后直接打开 `Prototype_07`，让该关卡原有 GameMode 重新创建正常的 PlayerController。

## 2. 创建资源目录

在 Content Browser 中创建：

```text
Content/Osaider/Intro/Blueprints
Content/Osaider/Intro/Maps
Content/Osaider/Intro/Media
Content/Osaider/Intro/Textures
Content/Osaider/Intro/UI
Content/Movies/Intro
```

注意：

`Content/Movies` 是 Unreal 对随项目发布媒体文件的特殊目录。Media Source 资产可以放在 `Content/Osaider/Intro/Media`，但它引用的 MP4 文件应放在 `Content/Movies/Intro`。

## 3. 准备第一版视频

建议第一版规格：

```text
File Name = Osaider_Intro_Loop.mp4
Container = MP4
Video Codec = H.264
Resolution = 1920 × 1080
Frame Rate = 30 fps
Bitrate = 8–15 Mbps
Pixel Aspect Ratio = 1.0
Audio = Optional
```

循环视频建议：

- 时长约 8–20 秒；
- 首帧与末帧的亮度、构图和运动方向尽量接近；
- 不使用突然闪白、硬切或强烈镜头摇动；
- 保持主体位于中央安全区域，避免超宽屏裁切时丢失；
- 画面运动以海雾、档案划痕、机械缓慢旋转和远景宫殿为主。

把视频复制到：

```text
Content/Movies/Intro/Osaider_Intro_Loop.mp4
```

如果 Unreal 弹出是否导入媒体文件的提示，可以接受；但后续仍应手动检查 File Media Source 路径。

## 4. 准备静态回退图

视频打开需要时间，也可能因为文件损坏或目标机器解码问题失败。因此必须准备静态背景：

```text
T_Intro_Fallback
```

建议规格：

- 1920 × 1080；
- 构图与视频首帧接近；
- 深海军蓝和黑色为主；
- 不把 Start 文案烘焙进图片；
- 不使用高饱和红蓝作为大面积背景。

导入到：

```text
Content/Osaider/Intro/Textures
```

默认情况下，回退图始终位于视频图层下方。视频没有画面时，它会自动成为背景。

## 5. 确定音频策略

第一版有两种选择：

### 静音循环视频

优点：

- 实现简单；
- 循环点不容易出现音频爆点；
- 视频解码与切关更稳定。

可以使用独立的环境声音或音乐 Blueprint 播放 Intro 音频。

### 带声音 MP4

需要在 Intro 关卡中添加 `Media Sound Component`，并绑定 `MP_Intro`。Widget 中的 Image 只能显示 Media Texture，不会自动播放视频音轨。

建议第一版先使用静音视频；页面流程稳定后再接入 Media Sound。

## 6. 记录目标地图

在开始搭建前确认 Content Browser 中现有游戏地图的实际名称。

本套文档暂按：

```text
Prototype_07
```

如果实际资产名称或路径不同，应在第 06 部分统一修改 `GameplayLevelName`，不要在多个 Blueprint 中分别硬编码。

## 7. 本部分验收

- [ ] Intro 目录已经创建。
- [ ] MP4 位于 `Content/Movies/Intro`。
- [ ] 视频使用 H.264 MP4，并能在系统播放器中正常播放。
- [ ] 已准备 `T_Intro_Fallback`。
- [ ] 已决定第一版是否需要视频音频。
- [ ] 已确认目标游戏地图的实际名称。
- [ ] 没有修改现有 Gameplay PlayerController。

## 常见错误

### 把 MP4 当成普通 Texture 导入

MP4 不通过 Texture Sample 播放。它需要 Media Source、Media Player 和 Media Texture。

### 视频放在 Content/Osaider/Intro/Media

编辑器中可能仍能播放，但不会像 `Content/Movies` 中的文件一样自动进入打包内容。把实际 `.mp4` 移到 `Content/Movies/Intro`。

### 一开始就使用 4K、60fps、高码率视频

这会增加首次打开时间、内存和解码压力。先用 1080p、30fps 验证完整流程，再按目标机器性能升级。
