# Osaider Cockpit UI Prototype v2.4

## 版本定位

v2.4 从 v2.0 重新分支，保留其档案阅读和物品分析结构，同时扩大观察区域，并将写实驾驶舱仪表转译为超现实的平面电子模块。

## 主要调整

- 放大中央观察窗，使建筑成为更强的画面主体。
- 观察窗采用非对称、被周边模块自然切割的轮廓，不使用规整矩形或八边形。
- 完整保留左侧录音档案的长文本、波形、频道、时码和播放控制。
- 保留右侧三个物品槽、READY 状态、`3 / 3 INPUT` 和 `ANALYZE` 操作。
- 底部仪表拆分为松散分布的色块信息岛，不再形成连续的写实仪表台。

## 视觉语言

- 暖黑、奶油黄、暗青绿、珊瑚红。
- 实心色块、简化符号、点阵和分段条形图。
- 使用明显的右下偏移硬投影，制造剪纸和舞台道具般的空间感。
- 仅保留抽象的不完整圆弧，不使用真实表盘、刻度盘和金属雷达框。
- 弱化军事科幻 HUD，强化不对称、梦境感与超现实电子剧场氛围。
