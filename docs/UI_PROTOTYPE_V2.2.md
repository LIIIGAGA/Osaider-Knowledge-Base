# Osaider Cockpit UI Prototype v2.2

## 设计方向

v2.2 将 v2.1 的复古机械仪表盘改为纯电子线框显示系统。中央观察窗和巨大建筑仍然是画面主体，所有功能信息集中在贴边的黑色显示区域中。

## 视觉特征

- 黑色显示底、青色主线框、橙红激活状态、暖白辅助信息。
- 细线裁角框、电子网格、波形、频谱柱、分段数字和像素状态格。
- 轻微 CRT 光晕、扫描线与屏幕噪点；不使用真实机械磨损。
- 移除实体表盘、金属雷达框、旋钮、拨杆、开关、键盘和立体按键。
- `ANALYZE` 改为平面电子指令区域，不表现为实体按钮。

## 功能布局

- 左侧：录音档案、频道、时码、波形和播放状态。
- 中央：大面积无遮挡观察窗。
- 右侧：三个线框物品槽、电子状态格、连接线路、READY 状态与分析指令。
- 底部：浅层频谱、线框导航图、数字读数与状态矩阵。
