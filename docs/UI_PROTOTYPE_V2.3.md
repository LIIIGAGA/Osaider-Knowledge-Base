# Osaider Cockpit UI Prototype v2.3

## 更新方向

v2.3 保留 v2.2 的纯电子线框结构，参考复古电子终端重新组织配色与屏幕氛围，没有加入实体表盘或机械控制器。

## 色彩层级

- 暖黑与深棕黑：显示器背景和负空间。
- 奶油黄与暗金黄：主要框架、档案标题和辅助信息。
- 暗青绿与祖母绿：运行状态、波形、导航和 READY 状态。
- 信号红与珊瑚红：物品槽激活状态、警示和 ANALYZE 指令。

## 屏幕质感

- 柔和的老式荧光屏余辉。
- 轻度边缘色彩溢出和横向刷新纹理。
- 克制的 CRT 扫描线、像素颗粒与暖色暗角。
- 所有效果保持平面化和非写实表达。
