# 第 05 部分：逐题选择与动画状态

## 本部分目标

让五组问题固定顺序播放。玩家点击任何普通答案后都进入同一个下一题，不修改游戏数据。完成第五题后显示最终重返 / 离开选择。

## 1. WBP_CycleReflection 变量

添加：

| 变量名 | 类型 | 默认值 | 用途 |
|---|---|---:|---|
| `Questions` | S_CycleReflectionQuestion Array | 5 项 | 问题内容 |
| `CurrentQuestionIndex` | Integer | 0 | 当前题目 |
| `bAcceptingInput` | Boolean | False | 防止动画中点击 |
| `bFinalDecisionVisible` | Boolean | False | 最终页状态 |
| `CreatedOptionWidgets` | WBP_CycleReflectionOption Array | Empty | 当前选项实例 |

不要创建：

```text
SelectedIdeology
FactionScore
AnswerHistorySave
WorldConsequence
```

## 2. Event Dispatcher

在 `WBP_CycleReflection` 创建：

```text
OnRestartRequested
OnLeaveRequested
```

两个 Dispatcher 都无输入。

Widget 不自己调用 `Open Level`。

## 3. Event Construct

```text
Event Construct
→ Set CurrentQuestionIndex = 0
→ Set bAcceptingInput = false
→ Set bFinalDecisionVisible = false
→ Set VB_QuestionPage Visibility = Hidden
→ Set VB_FinalDecision Visibility = Collapsed
→ Play ANIM_ScreenEnter
```

当 `ANIM_ScreenEnter` 完成：

```text
ShowQuestion(CurrentQuestionIndex)
```

不要在 Construct 同一帧显示第一题，否则文字会在世界尚未切黑时短暂出现。

## 4. ShowQuestion

创建函数：

```text
ShowQuestion
Input: QuestionIndex (Integer)
```

流程：

```text
Set bAcceptingInput = false
ClearChildren(VB_Options)
Clear CreatedOptionWidgets
IsValidIndex(Questions, QuestionIndex)
→ False: ShowFinalDecision
→ True:
   Get Questions[QuestionIndex]
   TXT_Progress.SetText("0X / 05")
   TXT_Question.SetText(QuestionText)
   For Each Options
      Create Widget WBP_CycleReflectionOption
      InitializeOption(ArrayIndex, OptionText)
      Bind OnOptionSelected → HandleCycleOptionSelected
      Add Child to Vertical Box(VB_Options)
      Add to CreatedOptionWidgets
   Set VB_QuestionPage Visibility = Visible
   Play ANIM_QuestionEnter
```

当 `ANIM_QuestionEnter` 完成：

```text
Set bAcceptingInput = true
```

## 5. HandleCycleOptionSelected

创建 Custom Event：

```text
HandleCycleOptionSelected
Input: SelectedIndex (Integer)
```

唯一允许的流程：

```text
Branch: bAcceptingInput == true
→ Set bAcceptingInput = false
→ For Each CreatedOptionWidgets
     Set bLocked = true
→ 可选：Print String
     [Reflection] Q=CurrentQuestionIndex Option=SelectedIndex
→ 播放被选项的本地 Pressed / Selected 反馈
→ Play ANIM_QuestionExit
```

这里禁止出现：

```text
Switch on SelectedIndex → 不同 Gameplay 分支
Set Ideology Value
Set Faction
Reveal Module
Save Game
Open Level
```

`SelectedIndex` 只用于调试和选中反馈，不用于决定下一题。所有选项都汇合到同一个 `ANIM_QuestionExit`。

## 6. 题目退出完成

当 `ANIM_QuestionExit` 完成：

```text
Set CurrentQuestionIndex = CurrentQuestionIndex + 1
Branch: CurrentQuestionIndex < Questions.Length
→ True: ShowQuestion(CurrentQuestionIndex)
→ False: ShowFinalDecision
```

不要使用一串 Delay。动画 Finished 是唯一推进点，避免低帧率下内容重叠。

## 7. ShowFinalDecision

创建函数：

```text
ShowFinalDecision
```

流程：

```text
Set bAcceptingInput = false
Set bFinalDecisionVisible = true
Set VB_QuestionPage Visibility = Collapsed
Set VB_FinalDecision Visibility = Visible
Set BTN_Restart IsEnabled = false
Set BTN_Leave IsEnabled = false
Play ANIM_FinalEnter
```

`ANIM_FinalEnter` 完成：

```text
Set BTN_Restart IsEnabled = true
Set BTN_Leave IsEnabled = true
Set bAcceptingInput = true
```

## 8. 最终按钮

`BTN_Restart.OnClicked`：

```text
Branch: bAcceptingInput && bFinalDecisionVisible
→ Set bAcceptingInput = false
→ Disable BTN_Restart
→ Disable BTN_Leave
→ Set PendingTravelChoice = Restart（仅 Widget 本地临时枚举或 Boolean）
→ Play ANIM_TravelOut
```

`BTN_Leave.OnClicked` 同理，临时选择为 Leave。

当 `ANIM_TravelOut` 完成：

```text
Branch PendingTravelChoice
→ Restart: Call OnRestartRequested
→ Leave: Call OnLeaveRequested
```

这个临时选择只用于决定切往哪个关卡，是本系统唯一允许的结果分支。

## 9. 不保存答案

本版本不需要 `SelectedAnswerIndices`。

原因：

- 用户要求选项不影响游戏世界；
- 不记录可以避免后续系统误用；
- 玩家反思发生在点击当下，不需要生成性格报告；
- 重开 `Prototype_07` 后 Widget 会被销毁，问题重新开始。

如果未来只为了研究测试记录匿名选择，应作为独立、明确授权的 Telemetry 需求重新设计，不能悄悄加入当前版本。

## 10. 动画和输入时序

推荐单题节奏：

```text
题目淡入 0.45 s
→ 玩家自由阅读
→ 点击选项
→ 选中状态停留 0.12–0.20 s
→ 淡出 0.25 s
→ 下一题淡入
```

不要自动计时替玩家选择，也不要提供默认焦点自动确认。

## 11. 本部分验收

- [ ] 第一题只在全黑后出现。
- [ ] 每题动态生成 3 个选项。
- [ ] 任意选项都进入同一下一题。
- [ ] 第 5 题后进入最终决定。
- [ ] 动画中所有按钮锁定。
- [ ] 快速双击不会跳过两题。
- [ ] Widget 没有保存普通答案。
- [ ] 只有最终按钮产生不同 Dispatcher。
