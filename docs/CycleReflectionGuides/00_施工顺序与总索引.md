# Osaider 循环结束反思界面：施工顺序与总索引

本套文档用于在 Unreal Engine 5.6 中制作完整叙事循环结束后的反思界面。

目标体验：

> 游戏世界淡出为纯黑。极淡的红蓝噪点底图随后显现。问题与选项依次出现在屏幕中央。玩家的回答只用于自我反思，不改变任何游戏世界状态。完成全部问题后，玩家只能选择重返 `Prototype_07`，或离开并返回 `L_Intro`。

## 1. 必须遵守的系统边界

1. 这里的“循环结束”指一次完整叙事循环结束，不是每次 Submission / Dice Check 后的模块循环。
2. 前五组问题的选项不修改：
   - `IdeologyValue`；
   - Archivist / Whalemen 路线；
   - Dice Check；
   - Inventory；
   - `SpawnedModules`；
   - 模块 Reveal 状态；
   - Game Instance；
   - Save Game。
3. 普通选项只执行两件事：播放一次选中反馈，然后进入下一题。
4. 只有最终决定产生导航结果：
   - `I want to return.` → 重新打开 `Prototype_07`；
   - `I want to leave.` → 打开 `L_Intro`。
5. 离开不是 `Quit Game`，而是返回 Intro。若未来需要退出桌面，应在 Intro 中另设按钮。
6. 红蓝噪点只表达世界中两种叙事力量的残留，不与任何具体答案绑定。
7. 不显示“正确”“错误”“阵营变化”或选择结果统计。
8. 不使用 `BP_ModuleBase`，不把反思题写进 `BP_CoreDevice` 或具体模块的机制图。

## 2. 推荐资源结构

在 Unreal Content Browser 中创建：

```text
Content/Osaider/CycleReflection/
├─ Blueprints/
│  ├─ BP_CycleReflectionManager
│  └─ BPI_CycleReflectionControl
├─ Data/
│  └─ S_CycleReflectionQuestion
├─ Textures/
│  └─ T_CycleReflection_BG_2560x1440
└─ UI/
   ├─ WBP_CycleReflection
   └─ WBP_CycleReflectionOption
```

红蓝噪点底图在 Photoshop 中完成，画布规格：

```text
2560 × 1440 px
16:9
RGB / 8-bit
sRGB IEC61966-2.1
```

导出并导入 Unreal 后命名：

```text
T_CycleReflection_BG_2560x1440
```

## 3. 总体职责

```text
最终模块或最终事件
→ BPI_CycleReflectionControl.StartCycleReflection
→ BP_CycleReflectionManager
→ 锁定 Gameplay 输入
→ 创建 WBP_CycleReflection
→ 淡入纯黑背景
→ 依次显示五组问题
→ 显示最终二选一
   ├─ Restart → Open Level Prototype_07
   └─ Leave   → Open Level L_Intro
```

职责分配：

| 资源 | 职责 |
|---|---|
| `S_CycleReflectionQuestion` | 保存单个问题与选项文本 |
| `WBP_CycleReflectionOption` | 显示一个可点击文本选项 |
| `WBP_CycleReflection` | 黑屏、噪点、逐题状态与动画 |
| `BP_CycleReflectionManager` | 单实例保护、输入锁定、绑定 Dispatcher、切关 |
| `BPI_CycleReflectionControl` | 让最终事件启动反思流程，避免模块依赖 UI 细节 |
| `BP_NoCharacterPlayerController` | 只增加通用的 Reflection 输入锁，不保存问题内容 |

## 5. 推荐施工顺序

1. 完成 01：所有资源已创建，空 Widget 可被 Manager 打开。
2. 完成 02：五组问题和最终文本录入完成。
3. 完成 03：黑底上的红蓝噪点足够淡，不影响阅读。
4. 完成 04：单题和三项长文本能在 1920 × 1080 中完整显示。
5. 完成 05：五题无分支地依次推进，并进入最终决定。
6. 完成 06：从真实循环结束事件触发，世界输入完全锁定。
7. 完成 07：重返与离开分别进入正确关卡。
8. 完成 08：完成完整测试后再移除调试 Print。

## 6. 最终验收

- [ ] 循环结束后先切黑，再出现第一题。
- [ ] 黑底始终完全遮住 Gameplay 世界。
- [ ] 红蓝噪点可感知但不抢夺注意力。
- [ ] 五组问题按固定顺序出现。
- [ ] 每个普通答案都进入同一个下一题。
- [ ] 普通答案不改变任何 Gameplay、路线或存档变量。
- [ ] 动画期间不能重复点击。
- [ ] 最终选择前不能跳回 Gameplay。
- [ ] 重返只打开一次 `Prototype_07`。
- [ ] 离开只打开一次 `L_Intro`。
- [ ] 自定义鼠标可见，系统白色鼠标不可见。
- [ ] 1920 × 1080、1600 × 900、2560 × 1440 下文本均可阅读。
