# 第 06 部分：循环结束触发与输入锁定

## 本部分目标

把完整叙事循环的最终完成事件接入 `BP_CycleReflectionManager`。启动时结束当前交互、锁住世界输入、关闭其他 UI，并确保反思 Widget 只有一个实例。

## 1. Manager BeginPlay

在 `BP_CycleReflectionManager.Event BeginPlay`：

```text
Get Player Controller 0
→ Cast to BP_NoCharacterPlayerController
→ Set GameplayPCRef
```

只在 BeginPlay 缓存一次。

如果 Cast 失败：

```text
Print String [Reflection][Error] Gameplay PC Missing
```

不要自动创建 Widget。反思界面必须等待完整循环结束事件。

## 2. Interface Event

实现：

```text
Event StartCycleReflection
```

流程：

```text
Branch: bReflectionActive == false
→ False: Return
→ True:
   Set bReflectionActive = true
   Set bTravelRequested = false
   IsValid(GameplayPCRef)
   → Invalid:
      Set bReflectionActive = false
      Print String [Reflection][Error] Gameplay PC Missing
   → Valid:
      Create Widget
         Class = ReflectionWidgetClass
         Owning Player = GameplayPCRef
      Set ReflectionWidgetRef
      IsValid(ReflectionWidgetRef)
      → Invalid:
         Set bReflectionActive = false
         Set ReflectionWidgetRef = None
         Print String [Reflection][Error] Widget Create Failed
      → Valid:
         Bind OnRestartRequested → HandleRestartRequested
         Bind OnLeaveRequested → HandleLeaveRequested
         Add to Viewport ZOrder = 900
         GameplayPCRef.EnterCycleReflectionMode(ReflectionWidgetRef)
```

如果 Create Widget 失败：

```text
Set bReflectionActive = false
Set ReflectionWidgetRef = None
Print String [Reflection][Error] Widget Create Failed
```

因为本方案把 `EnterCycleReflectionMode` 放在 Widget 验证和 Add to Viewport 之后，
Create Widget 失败时尚未锁定 Gameplay 输入，所以这里不需要调用
`ExitCycleReflectionMode`。该错误恢复函数只用于“已经成功进入 Reflection Mode 后”
发生的调试或异常恢复。

## 3. 接入最终完成事件

推荐方式：在最终模块或最终流程 Actor 的完成事件中寻找 Manager，然后调用 Interface。

```text
OnFinalCycleCompleted
→ Get Actor of Class(BP_CycleReflectionManager)
→ Does Implement Interface(BPI_CycleReflectionControl)
→ StartCycleReflection (Message)
```

`Get Actor of Class` 只在完整循环结束时执行一次，可以接受。不要放在 Tick。

如果最终模块已经有明确的 Manager Instance Reference，也可以直接发送 Interface Message。

不要让最终模块：

- 创建 `WBP_CycleReflection`；
- 保存问题内容；
- 直接 Open Level；
- 修改 PlayerController 输入细节。

模块只发出“完整循环已结束”的请求。

## 4. 关闭现有 UI

在 `EnterCycleReflectionMode` 中按现有引用安全处理：

```text
If Valid(SubmissionPanelRef)
→ 调用它已有的安全关闭函数，或 Remove from Parent

If Valid(InventoryPanelRef)
→ 安全关闭

If Valid(ItemPopupRef)
→ 安全关闭
```

优先调用现有 Close 函数，让各 Widget 自己清理状态；只有没有关闭接口时才直接 Remove。

不要清空 Inventory、SubmittedItems 或 PendingRevealModule。反思界面只是遮住当前世界，最终切关会自然重建关卡。

## 5. 结束 Drag 与相机输入

锁定前必须先结束正在进行的交互：

```text
If bDragging && IsValid(CurrentDragTarget)
→ BPI_ModuleInteractable.EndDrag(CurrentDragTarget)

Set bDragging = false
Set CurrentDragTarget = None
Set bHoldingRMB = false
Set bCameraSplineEnabled = false（仅当前关卡生命周期）
```

否则黑屏后仍可能听到轮盘声、拖拽物继续移动或相机在背景中滑动。

如当前 Drag 系统有 Loop Sound，确保 `EndDrag` 会停止声音。

## 6. 输入模式

Manager 创建 Widget 后，PlayerController 设置：

```text
Set Input Mode Game and UI
Player Controller = Self
In Widget to Focus = ReflectionWidgetRef
Mouse Lock Mode = Do Not Lock
Hide Cursor During Capture = false
```

随后重新应用项目已有 Custom Cursor Mode。

Gameplay 自定义鼠标实例的当前变量名是：

```text
CursorWidgetRef
```

切换输入模式后使用 `Is Valid(CursorWidgetRef)`，再调用它的
`SetCursorState(Normal)`。不要另建 `MouseCursorRef`；后者只可能出现在独立
Intro Controller 的实现中。

不要使用 UI Only。项目的自定义鼠标依赖正常更新与既有 Controller 流程，`Game and UI` 加上 `bCycleReflectionOpen` 输入守卫更安全。

## 7. 世界输入守卫

在 Gameplay 输入事件的最前面检查：

```text
if bCycleReflectionOpen
→ Return
```

特别测试：

- 反思界面出现时按 Space，宫殿不旋转；
- 按 D，不出现 Submission；
- 按 Enter，不执行 Dice Check；
- 按 L，不切换手电；
- RMB 不移动相机；
- 点击选项外的黑屏，不命中世界 Actor。

全屏根控件可以保持 `Visible` 以拦截点击；只有背景视觉子控件设为 Not Hit-Testable。

## 8. 音频处理

推荐第一版：

- 停止当前 Voice Component；
- 停止交互 Loop Sound；
- 环境音在黑屏开始时 0.5–1.0 秒淡出；
- 反思问题保持安静或只保留极低的底噪；
- 普通答案只使用很轻的中性点击声；
- 不用红蓝阵营音效评价选择。

如果当前没有统一 Audio Manager，先不新增复杂混音系统。至少确保 Drag Loop 不会残留。

## 9. 错误恢复函数

在 PlayerController 创建：

```text
ExitCycleReflectionMode
```

仅用于 Widget 创建失败或 PIE 调试恢复：

```text
Set bCycleReflectionOpen = false
Set bUIInteractionLocked = false
Set Input Mode Game and UI 或项目正常 Gameplay 模式
恢复 Custom Cursor Mode
```

正式成功路径不调用它，因为最终一定会切关。

## 10. 本部分验收

- [ ] 只有完整循环结束事件能启动 Manager。
- [ ] Manager 只创建一个 Widget。
- [ ] 最终模块只发送启动请求，不拥有 UI 逻辑。
- [ ] 当前 Drag、RMB 和其他输入在切黑前安全结束。
- [ ] 现有 UI 被关闭但数据没有被修改。
- [ ] 黑屏背后不能与世界互动。
- [ ] 自定义鼠标仍可点击选项。
