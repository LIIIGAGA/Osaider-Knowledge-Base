# 第 07 部分：重返、离开与切关

## 本部分目标

让最终两个按钮在动画结束后分别打开 `Prototype_07` 与 `L_Intro`。Widget 负责表现与广播，Manager 负责关卡导航。

## 1. 绑定 Dispatcher

在 `BP_CycleReflectionManager.StartCycleReflection` 的 Create Widget 之后：

```text
Bind Event to OnRestartRequested
Target = ReflectionWidgetRef
Event = HandleRestartRequested

Bind Event to OnLeaveRequested
Target = ReflectionWidgetRef
Event = HandleLeaveRequested
```

在 Add to Viewport 之前完成绑定，避免极端情况下漏掉事件。

## 2. HandleRestartRequested

创建 Custom Event：

```text
HandleRestartRequested
```

流程：

```text
Branch: bTravelRequested == false
→ False: Return
→ True:
   Set bTravelRequested = true
   IsValid(GameplayPCRef.CursorWidgetRef)
   → Remove from Parent（如果当前关卡切换流程需要手动移除）
   Open Level by Name
      Level Name = RestartLevelName
      Absolute = true
```

默认：

```text
RestartLevelName = Prototype_07
```

重新打开同一关卡会自然重建：

- PlayerController；
- CoreDevice；
- Inventory；
- Module Reveal 状态；
- Reflection Manager；
- Reflection Widget。

本方案不额外调用一串手动 Reset，避免旧引用残留。

## 3. HandleLeaveRequested

创建：

```text
HandleLeaveRequested
```

流程与 Restart 相同，只改变关卡名：

```text
Branch: bTravelRequested == false
→ Set bTravelRequested = true
→ Open Level by Name
   Level Name = IntroLevelName
   Absolute = true
```

默认：

```text
IntroLevelName = L_Intro
```

`L_Intro` 会使用自己的 `GM_Intro` 和 `BP_IntroPlayerController`，重新创建 Intro 页面与自定义鼠标。

不要从 Gameplay 关卡复用或携带 Reflection Widget、Gameplay Mouse Cursor 到 Intro。

## 4. 切关前保持全黑

Widget 的 `ANIM_TravelOut` 应完成：

1. 问题或最终文字淡出；
2. 两个按钮消失；
3. 红蓝噪点减弱或消失；
4. `Border_Black` 保持 Opacity 1；
5. 广播最终 Dispatcher；
6. Manager 执行 Open Level。

不要先 Remove Reflection Widget 再 Open Level，否则可能闪回 Gameplay 世界一帧。

## 5. 两个选择的叙事对称性

在 UI 上不要把某一个按钮设计成默认正确答案：

```text
Restart 与 Leave：
- 相同尺寸
- 相同字体
- 相同 Hover
- 相同点击音量
- 相同出现时机
```

只有其文字和导航目标不同。

“重返”不自动等于服从；它也可能表示继续寻找。

“离开”不自动等于胜利；它也意味着停止见证，并失去当前循环中获得的一切。

这些含义留给玩家，不通过颜色或奖励判定。

## 6. 地图打包检查

打开 Project Settings：

```text
Project Settings
→ Packaging
→ List of Maps to Include in a Packaged Build
```

确认至少包含：

```text
L_Intro
Prototype_07
```

并确认：

```text
Game Default Map = L_Intro
Editor Startup Map = 按当前项目需要
```

如果项目当前 Default Map 尚未切换到 `L_Intro`，先按 IntroGuides 完成并测试，不要在本步骤重复创建 Intro 系统。

## 7. 防重复保护

需要三层保护：

1. Manager：`bReflectionActive` 防止重复创建 Widget；
2. Widget：`bAcceptingInput` 防止动画期间重复点击；
3. Manager：`bTravelRequested` 防止 Open Level 调用两次。

不要只依赖 Button Disabled。一帧内连续输入或多个输入设备可能在 Disabled 生效前再次触发。

## 8. 不要使用 Quit Game

当前“离开”的产品定义是：

```text
退出循环 → 返回 L_Intro
```

不是：

```text
Quit Game
```

这使玩家可以在 Intro 停留、重新开始或使用未来的独立退出按钮。

## 9. 本部分验收

- [ ] Widget 不含 Open Level 节点。
- [ ] Restart 只打开一次 `Prototype_07`。
- [ ] Leave 只打开一次 `L_Intro`。
- [ ] 切关前始终保持全黑，没有闪回世界。
- [ ] 两个按钮没有红蓝阵营提示。
- [ ] 两张地图已加入打包列表。
- [ ] 返回 Intro 后 Intro 鼠标与 Start 正常。
