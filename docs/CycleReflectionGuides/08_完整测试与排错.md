# 第 08 部分：完整测试与排错

## 本部分目标

验证循环结束反思界面的内容、无后果边界、输入锁、动画、切关和不同分辨率。不要只测试一遍正常点击。

## 1. 调试 Print

施工阶段保留：

```text
[Reflection] Start Requested
[Reflection] Widget Created
[Reflection] Screen Black Complete
[Reflection] Show Question = Reflection_0X
[Reflection] Option Clicked Q=X Option=Y
[Reflection] Show Final Decision
[Reflection] Restart Requested
[Reflection] Leave Requested
[Reflection] Open Level = LevelName
[Reflection][Error] Widget Create Failed
[Reflection][Error] Duplicate Start Rejected
[Reflection][Error] Duplicate Travel Rejected
```

普通答案 Print 只能显示索引，不写入任何 Gameplay 值。

## 2. 测试 A：触发边界

执行普通 Submission 与 Dice Check。

预期：

- Reflection 不出现；
- Manager 的 `bReflectionActive` 仍为 False。

完成最终叙事事件。

预期：

- Reflection 只出现一次；
- 先切黑，再显示第一题。

## 3. 测试 B：黑屏时序

录屏逐帧检查：

1. Gameplay 世界仍可见；
2. 黑色 Opacity 上升；
3. 世界完全不可见；
4. 红蓝噪点缓慢出现；
5. 第一题出现。

不应发生：

- 第一题在世界画面上提前显示；
- Texture 第一帧白闪或尚未加载；
- 黑底透明露出宫殿；
- 噪点比问题更亮。

## 4. 测试 C：普通答案无后果

在启动反思前记录：

```text
IdeologySum
FinalScore
SubmittedItems
Inventory Length
SpawnedModules Length
当前 Reveal Actors
GI 中相关变量
Save Slot 时间戳（若存在）
```

分别测试每题的 3 个答案。每次点击后检查：

- 只进入下一题；
- 上述 Gameplay 值不变化；
- 没有 Save Game 调用；
- 没有模块 Reveal / Hide；
- 没有红蓝反馈评价答案。

为了覆盖所有组合，不需要测试 3⁵ 个完整排列。至少完成：

- 全选第一项；
- 全选第二项；
- 全选第三项；
- 一组混合选择。

四次运行的最终页应完全相同。

## 5. 测试 D：逐题顺序

预期固定顺序：

```text
Reflection_01
→ Reflection_02
→ Reflection_03
→ Reflection_04
→ Reflection_05
→ Final Decision
```

检查：

- 不跳题；
- 不重复题；
- Progress 为 01/05 至 05/05；
- 每题恰好 3 项；
- 最终页恰好 2 个按钮。

## 6. 测试 E：压力输入

尝试：

- 双击普通选项；
- 在淡出时点击另一项；
- 同时鼠标点击和键盘确认；
- 快速交替点击 Restart / Leave；
- 在最终动画出现前连续点击；
- 连续两次调用 `StartCycleReflection`。

预期：

- 一次点击最多推进一题；
- 不会同时播放两个 Question Animation；
- 只存在一个 Reflection Widget；
- 只广播一个 Travel Dispatcher；
- 只调用一次 Open Level。

## 7. 测试 F：世界输入锁

- LMB 点击世界 InteractionPoint；
- LMB 拖动机械；
- RMB 移动 Camera Spline；
- Space 旋转宫殿；
- D 打开 Submission；
- Enter 触发 Check；
- L 切换 Flashlight。

预期：全部无效，但 UI 选项仍能 Hover 和点击。

同时检查：

- 没有残留轮盘 Loop Sound；
- 相机不在背景继续移动；
- Item Popup 不覆盖 Reflection；
- 自定义鼠标没有被黑底挡住。

4. 新关卡重新创建正常 PlayerController；

6. 游戏从新循环的正确初始状态开始。

## 9. 测试 H：离开

重新完成流程，选择：

```text

```

预期：

1. 只执行一次 `Open Level L_Intro`；
2. `GM_Intro` 与 `BP_IntroPlayerController` 生效；

至少测试：


## 11. 测试 J：底图与可读性

在明亮与昏暗显示器设置下检查：

- 黑底接近纯黑；
- 红蓝只在背景中若隐若现；
- 不出现大片饱和紫色；

## 12. 常见错误

### 点击一个答案跳过两题

- `bAcceptingInput` 没有在第一次点击立即设为 False；
- 每次 ShowQuestion 重复 Bind 同一个旧 Widget；
- Animation Finished 被绑定多次；
- 同一 Button 同时使用 OnPressed 与 OnClicked 推进。

正式推进只放在 OnClicked → `HandleOptionSelected`，动画完成后只递增一次。

### 选择不同答案出现不同最终页

说明普通答案被接入了分支。搜索：

```text
SelectedIndex
Switch on Int
Ideology
Faction
Set Members
```

普通答案只能汇入统一 Question Exit。

### 黑屏出现但仍能操作世界

- `bCycleReflectionOpen` 没覆盖全部输入入口；
- Root Visibility 不能拦截空白区域；
- `Set Input Mode` 后没有设置 Focus；
- Drag 在锁定前没有 EndDrag。

### 自定义鼠标消失

- Reflection Widget ZOrder 高于鼠标；
- Input Mode 改变后没有重新 Apply Custom Cursor Mode；
- Mouse Cursor Widget 被错误 Remove；
- 系统使用 UI Only 导致既有更新路径停止。

### 看到 Windows 白色鼠标

检查项目 Software Cursor 仍指向 `WBP_InvisibleSystemCursor`，并保持现有自定义鼠标方案。不要为 Reflection 新建 Hardware Cursor。

### 返回 Intro 后出现两个鼠标

Gameplay 鼠标被错误保存到 Game Instance 或跨关卡复用。关卡切换前可移除当前实例；`BP_IntroPlayerController` 只创建自己的一个实例。

### 底图被拉伸或变形

- `IMG_Background` 被直接铺满 Canvas；
- 没有使用 `ScaleBox_Background`；
- Scale Box 的 Stretch 不是 `Scale To Fill`；
- Scale Box 没有 Clip to Bounds。

### 底图第一帧白闪

- `Border_Black` 没有作为独立兜底层；
- Texture 尚未加载时 Image 使用了白色默认 Brush；
- `T_CycleReflection_BG_2560x1440` 没有设置 Never Stream；
- Screen Enter 动画在黑底完全覆盖前显示了背景 Image。

### 噪点太亮

回到 PSD 降低红蓝噪点图层强度，保持黑底为 `#020204` 后重新导出。不要降低文字亮度来迁就背景，也不要在 Widget 中叠加半透明灰色遮罩掩盖错误的底图强度。

### 打包版无法切关

确认 `L_Intro` 和 `Prototype_07` 都在 Packaging 的地图列表中，Name 拼写完全一致。
