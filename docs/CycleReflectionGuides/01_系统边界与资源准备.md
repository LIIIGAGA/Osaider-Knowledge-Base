# 第 01 部分：系统边界与资源准备

## 本部分目标

创建循环结束反思界面的资源骨架，并在连线前锁定“普通答案不影响游戏世界”的技术边界。

## 1. 明确触发时机

本系统只在一次完整叙事循环结束时启动。

不要连接到：

- `PrepareDiceCheck`；
- `CommitPendingReveal`；
- 每次模块 Reveal；
- Submission Widget 淡出；
- 每次领取物品；
- 普通关卡重置函数。

推荐连接到：

- 最终模块的完成事件；
- 最后一个叙事阶段的结束 Dispatcher；
- 或专门的 `BP_CycleEndTrigger`。

如果当前最终事件还未完成，先在 `BP_CycleReflectionManager` 创建一个临时调试按键或编辑器可调用事件，独立验证界面，不要提前把它接到 Dice Check。

## 2. 创建目录

在 Content Browser 创建：

```text
Content/Osaider/CycleReflection/Blueprints
Content/Osaider/CycleReflection/Data
Content/Osaider/CycleReflection/Textures
Content/Osaider/CycleReflection/UI
```

## 3. 创建问题 Struct

在 `Data` 中创建 Blueprint Structure：

```text
S_CycleReflectionQuestion
```

字段：

| 字段 | 类型 | 用途 |
|---|---|---|
| `QuestionID` | Name | 调试与排序，不显示给玩家 |
| `QuestionText` | Text | 屏幕中央问题 |
| `Options` | Text Array | 本题全部选项 |

不要添加：

- Ideology Value；
- Faction；
- Next Module；
- Gameplay Tag；
- Save Key；
- Branch ID。

Struct 中没有这些字段，可以从数据层阻止普通答案意外变成路线选择。

## 4. 创建 Interface

在 `Blueprints` 中创建 Blueprint Interface：

```text
BPI_CycleReflectionControl
```

添加函数：

```text
StartCycleReflection
```

无输入，无输出。

该 Interface 只负责“请求启动反思界面”，不传入 Archivist / Whalemen 结果，也不传入 Dice Score。

## 5. 创建 Manager

创建 Actor Blueprint：

```text
BP_CycleReflectionManager
```

实现：

```text
BPI_CycleReflectionControl
```

添加变量：

| 变量名 | 类型 | 默认值 | 用途 |
|---|---|---|---|
| `ReflectionWidgetClass` | WBP_CycleReflection Class Reference | WBP_CycleReflection | 界面类 |
| `ReflectionWidgetRef` | WBP_CycleReflection Object Reference | None | 当前实例 |
| `GameplayPCRef` | BP_NoCharacterPlayerController Object Reference | None | 输入锁定与鼠标 |
| `bReflectionActive` | Boolean | False | 防止重复打开 |
| `bTravelRequested` | Boolean | False | 防止重复切关 |
| `RestartLevelName` | Name | Prototype_07 | 重返关卡 |
| `IntroLevelName` | Name | L_Intro | 离开后的关卡 |

把一个 `BP_CycleReflectionManager` 放入 `Prototype_07`。

关卡中只允许存在一个实例。

## 6. 创建两个 Widget

在 `UI` 中创建：

```text
WBP_CycleReflection
WBP_CycleReflectionOption
```

第一阶段只需保证它们能编译，不必立即完成视觉。

## 7. 允许 PlayerController 进入反思模式

在 `BP_NoCharacterPlayerController` 增加通用变量：

```text
bCycleReflectionOpen : Boolean = false
```

增加函数：

```text
EnterCycleReflectionMode
```

第一版职责：

```text
Set bCycleReflectionOpen = true
Set bUIInteractionLocked = true
If bDragging
→ 对 CurrentDragTarget 调用 EndDrag
Set bDragging = false
Set bHoldingRMB = false
关闭或隐藏 Inventory / Submission / Item Popup
Set Input Mode Game and UI
Show Mouse Cursor = true
Is Valid(CursorWidgetRef)
→ CursorWidgetRef.SetCursorState(Normal)
```

`CursorWidgetRef` 是当前 `BP_NoCharacterPlayerController` 已经创建并保存的
Gameplay 自定义鼠标实例。反思界面只复用它，不创建第二个鼠标 Widget。

在以下输入入口最前面加入：

```text
Branch: bCycleReflectionOpen == false
```

至少覆盖：

- HoverTrace；
- LMB 世界点击；
- Drag；
- RMB Camera Spline；
- Space 全局旋转；
- D / Submission；
- Enter / Dice Check；
- L / Flashlight。

这里增加的是全局 UI 输入锁，不是模块机制逻辑，因此仍符合 PlayerController 的职责。

不要使用 `Set Game Paused(true)` 作为第一版方案。暂停会改变世界与音频时序，使切关和动画调试复杂；全屏黑色已经遮住世界，明确锁定输入即可。

## 8. 禁止的连接

全文档施工期间，普通选项的 OnClicked 不得连接到：

```text
BP_CoreDevice
GIRef
Inventory
SpawnedModules
IdeologySum
FinalScore
RevealModuleGroup
SaveGameToSlot
OpenLevel
```

`OpenLevel` 只允许出现在 Manager 的最终重返 / 离开处理函数中。
