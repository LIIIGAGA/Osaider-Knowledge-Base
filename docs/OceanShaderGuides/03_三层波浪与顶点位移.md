# 第 03 部分：双层大尺度波浪与顶点位移

## 本部分目标

针对当前 `Ocean_Near = 2 × 2 km`、实际顶点间距约 10 m 的网格，在材质中叠加两层方向不同的大尺度波浪，同时得到：

- 顶点位移 `WaveOffsetWS`；
- 总高度 `WaveHeight`；
- X、Y 两个方向的坡度；
- 可连接到 `Normal` 的世界空间法线。

本部分使用可读性较高的正弦波组合。几何只负责 60–200 m 的大形波浪；短于约 60 m 的细节不进入 WPO，改由第 04、05 部分的切色、法线和泡沫表现。

## 1. 波浪公式

每层波浪使用：

```text
K = 2 × PI / Wavelength
Phase = Dot(WorldXY, DirectionXY) × K + Time × Speed + PhaseOffset
Height = sin(Phase) × Amplitude
SlopeX = cos(Phase) × Amplitude × K × DirectionX
SlopeY = cos(Phase) × Amplitude × K × DirectionY
```

其中：

- `Amplitude`：厘米；
- `Wavelength`：厘米；
- `Speed`：相位变化速度，单位可理解为弧度／秒；
- `DirectionXY`：必须是归一化二维方向；
- `WorldXY`：世界空间位置的 X、Y。

## 2. 创建 `MF_OS_WaveSingle`

在 `Materials/Functions` 中创建 Material Function：

`MF_OS_WaveSingle`

创建 Function Input：

| 输入 | 类型 |
|---|---|
| `WorldXY` | Vector2 |
| `TimeValue` | Scalar |
| `DirectionXY` | Vector2 |
| `Amplitude` | Scalar |
| `Wavelength` | Scalar |
| `Speed` | Scalar |
| `PhaseOffset` | Scalar |

创建 Function Output：

| 输出 | 类型 |
|---|---|
| `Height` | Scalar |
| `SlopeX` | Scalar |
| `SlopeY` | Scalar |

### 2.1 创建第一个 Function Input

1. 双击打开 `MF_OS_WaveSingle`。
2. 在空白 Graph 中点击鼠标右键。
3. 搜索 `Function Input`。
4. 点击搜索结果中的 `Function Input`，放入 Graph。
5. 选中这个节点，在左侧或右侧 Details 面板中找到 `Input` 设置。
6. 将 `Input Name` 改为 `WorldXY`。
7. 将 `Input Type` 改为 `Vector2`。
8. 将 `Sort Priority` 设置为 `0`。

如果没有看到 Details 面板，使用顶部菜单：

```text
Window → Details
```

不要创建 `Vector Parameter`。Material Function 对外暴露引脚必须使用 `Function Input`。

### 2.2 复制并设置其余输入

选中 `WorldXY` 节点，按 `Ctrl + W` 复制六次。逐个设置：

| Input Name | Input Type | Sort Priority | Preview Value |
|---|---|---:|---|
| `WorldXY` | Vector2 | 0 | `(0,0)` |
| `TimeValue` | Scalar | 1 | `0` |
| `DirectionXY` | Vector2 | 2 | `(1,0)` |
| `Amplitude` | Scalar | 3 | `300` |
| `Wavelength` | Scalar | 4 | `20000` |
| `Speed` | Scalar | 5 | `0.18` |
| `PhaseOffset` | Scalar | 6 | `0` |

对每个输入勾选 `Use Preview Value as Default`。这样函数单独预览或暂时没有连接某个输入时，会使用表中的测试值。

`Preview Value` 只用于函数默认预览。第 04 节在主材质调用函数时，主材质参数会覆盖这些值。

### 2.3 创建 Function Output

新建 Material Function 时，Graph 中通常已经有一个 `Function Output` 节点。如果存在：

1. 选中它。
2. 在 Details 中把 `Output Name` 改为 `Height`。
3. 把 `Sort Priority` 设置为 `0`。
4. 按 `Ctrl + W` 复制两次。
5. 第二个命名为 `SlopeX`，Sort Priority 设置为 `1`。
6. 第三个命名为 `SlopeY`，Sort Priority 设置为 `2`。

如果 Graph 中没有 Function Output：

1. 在空白处右键。
2. 搜索 `Function Output`。
3. 放入三个 Function Output 节点。
4. 分别命名为 `Height`、`SlopeX`、`SlopeY`。

`Function Output` 不需要设置 Input Type。连接到它的表达式是 Scalar，它就会输出 Scalar。

### 2.4 先消除临时编译错误

波浪公式还没有搭建时，三个 Output 可能因为没有输入而报错。创建一个值为 `0` 的 Constant，然后把它暂时连接到：

```text
0 → Height
0 → SlopeX
0 → SlopeY
```

点击顶部 `Apply` 和 `Save`。下一节搭建公式时，再用真正的计算结果替换这些临时连线。

完成后，Graph 中应该有：

```text
左侧：7 个 Function Input
右侧：3 个 Function Output
```

## 3. 搭建单层波节点

按以下顺序连接：

```text
Wavelength
→ Divide：6.283185 / Wavelength
→ 得到 K

DotProduct(WorldXY, DirectionXY)
→ Multiply K
→ Add(TimeValue × Speed)
→ Add PhaseOffset
→ 得到 Phase

Sine(Phase) × Amplitude
→ Height

Cosine(Phase) × Amplitude × K × DirectionXY.R
→ SlopeX

Cosine(Phase) × Amplitude × K × DirectionXY.G
→ SlopeY
```

### 3.1 具体搭建 SlopeX 和 SlopeY

这两个输出共用同一个 `Cosine` 结果，不需要创建两套 Cosine。

#### A. 创建共同的坡度基础值

1. 在 Graph 空白处右键，搜索并创建 `Cosine`。
2. 把前面计算完成的 `Phase` 连接到 Cosine 输入。
3. 选中 Cosine，在 Details 中把 `Period` 设置为 `6.283185`。
4. 创建一个 `Multiply`，连接：

```text
Cosine 输出 → Multiply_1.A
Amplitude   → Multiply_1.B
```

5. 再创建一个 `Multiply`，连接：

```text
Multiply_1 输出 → Multiply_2.A
K                → Multiply_2.B
```

把 `Multiply_2` 的输出理解为：

```text
SlopeBase = Cosine(Phase) × Amplitude × K
```

#### B. 拆出 DirectionXY 的 X 和 Y

1. 从 `DirectionXY` Function Input 的输出引脚拖一条线。
2. 搜索 `Normalize` 并连接，确保输入方向长度为 1。
3. 从 Normalize 输出拖线，搜索 `Component Mask`。
4. 创建第一个 Component Mask，只勾选 `R`，作为 `DirectionX`。
5. 复制该节点，第二个只勾选 `G`，作为 `DirectionY`。

在 Vector2 中：

```text
R = X
G = Y
```

前面计算 `Phase` 的 `DotProduct(WorldXY, DirectionXY)` 也应连接这个 Normalize 输出，不要一处用原始 Direction、另一处用归一化 Direction。

#### C. 输出 SlopeX

创建第三个 Multiply：

```text
SlopeBase  → Multiply_3.A
DirectionX → Multiply_3.B
Multiply_3 → Function Output：SlopeX
```

#### D. 输出 SlopeY

创建第四个 Multiply：

```text
SlopeBase  → Multiply_4.A
DirectionY → Multiply_4.B
Multiply_4 → Function Output：SlopeY
```

最终结构：

```text
Phase → Cosine(Period 6.283185)
                  │
Amplitude ─────── ×
                  │
K ─────────────── × ───── SlopeBase
                            ├─ × DirectionXY.R → SlopeX
DirectionXY → Normalize ────┤
                            └─ × DirectionXY.G → SlopeY
```

如果 `DirectionXY = (1,0)`，`SlopeY` 输出为 0 是正确结果，因为这层波只沿 X 方向变化。使用次浪方向 `(0.34,0.94)` 时，SlopeX 和 SlopeY 都会有数值。

### 必须设置 Sine/Cosine 的 Period

选中本函数内的 `Sine` 和 `Cosine` 节点，把两者的 `Period` 都设置为：

```text
6.283185
```

这样节点输入可按弧度理解，本文的 `K = 2PI / Wavelength`、`PhaseOffset` 和 `Speed` 参数才能直接使用。

如果保留节点默认的 `Period = 1`，就必须把 K 改为 `1 / Wavelength`，同时把 Speed 和 PhaseOffset 都改用“周期”单位；不要混用两套单位。

完成后做一次验证：WorldXY 沿波浪方向移动一个 `Wavelength`，结果必须恰好重复一次。

## 4. 在主材质创建两组几何波参数

### 主浪 Main

| 参数 | 默认值 |
|---|---:|
| `Main_Amplitude` | 300 |
| `Main_Wavelength` | 20000 |
| `Main_Speed` | 0.18 |
| `Main_Direction` | `(1.0, 0.0)` |
| `Main_Phase` | 0.0 |

### 次浪 Secondary

| 参数 | 默认值 |
|---|---:|
| `Secondary_Amplitude` | 100 |
| `Secondary_Wavelength` | 7000 |
| `Secondary_Speed` | 0.30 |
| `Secondary_Direction` | `(0.34, 0.94)` |
| `Secondary_Phase` | 1.7 |

### 碎浪 Detail：保留参数但关闭几何位移

| 参数 | 默认值 |
|---|---:|
| `Detail_Amplitude` | 0 |
| `Detail_Wavelength` | 2500 |
| `Detail_Speed` | 0.45 |
| `Detail_Direction` | `(-0.77, 0.64)` |
| `Detail_Phase` | 3.1 |

### 4.1 创建 `Main_Direction`

回到主材质 `M_OS_StylizedOcean`，不要在 `MF_OS_WaveSingle` 内创建这个参数。

1. 在主材质 Graph 空白处右键。
2. 搜索 `Vector Parameter`。
3. 创建节点并命名为 `Main_Direction`。
4. 选中节点，在 Details 的 Default Value 中直接填写：

```text
R = 1.0
G = 0.0
B = 0.0
A = 0.0
```

这里不是在选择颜色。通道含义为：

```text
R = Direction X
G = Direction Y
B、A = 不使用
```

5. 给它设置 Parameter Group：`03_Waves_Main`。
6. 从 `Main_Direction` 输出拖线，创建 `Component Mask`。
7. 在 Component Mask 中只勾选 `R` 和 `G`。
8. 将 Component Mask 的输出连接到主浪 `MF_OS_WaveSingle` 节点的 `DirectionXY` 输入。

连接结构：

```text
Main_Direction Vector Parameter
R=1, G=0, B=0, A=0
→ Component Mask RG
→ Wave_Main.DirectionXY
```

也可以按住键盘 `V` 并在 Graph 空白处单击鼠标左键，快速创建 Vector Parameter。

### 4.2 创建 `Secondary_Direction`

复制 `Main_Direction`，命名为 `Secondary_Direction`，设置：

```text
R = 0.34
G = 0.94
B = 0.0
A = 0.0
Parameter Group = 04_Waves_Secondary
```

同样经过一个只勾选 R、G 的 Component Mask，再连接：

```text
Secondary_Direction
→ Component Mask RG
→ Wave_Secondary.DirectionXY
```

不要通过颜色 Hex 输入方向数值；直接填写 R、G 数字。

方向使用 Vector Parameter，只读取 R、G。确保方向长度接近 1；也可以在函数内用 `Normalize`。

`Detail_Amplitude` 必须保持 0。当前 10 m 顶点间距无法稳定表现 25 m 波长；这个参数只保留给未来重建高密度 Near 网格时使用。

## 6. 调用两次 WaveSingle

放置两次 `MF_OS_WaveSingle`：

```text
Wave_Main
Wave_Secondary
```

分别连接对应参数。

### 6.1 两个函数节点必须连接的全部输入

如果 `MF_OS_WaveSingle` 节点底部显示红色 `ERROR!`，首先检查是否遗漏了必需输入。

两个函数共用：

```text
Time 或 DEBUG_FreezeWaves 输出
├─→ Wave_Main.TimeValue
└─→ Wave_Secondary.TimeValue

Absolute World Position (Excluding Material Shader Offsets)
→ Component Mask RG
├─→ Wave_Main.WorldXY
└─→ Wave_Secondary.WorldXY
```

主浪单独连接：

```text
Main_Direction → Mask RG → Wave_Main.DirectionXY
Main_Amplitude             → Wave_Main.Amplitude
Main_Wavelength            → Wave_Main.Wavelength
Main_Speed                 → Wave_Main.Speed
Main_Phase                 → Wave_Main.PhaseOffset
```

次浪单独连接：

```text
Secondary_Direction → Mask RG → Wave_Secondary.DirectionXY
Secondary_Amplitude             → Wave_Secondary.Amplitude
Secondary_Wavelength            → Wave_Secondary.Wavelength
Secondary_Speed                 → Wave_Secondary.Speed
Secondary_Phase                 → Wave_Secondary.PhaseOffset
```

所有输入圆点都应显示为已连接状态。不要只连接 Height、Slope 输出。

### 6.2 World Position 模式检查

选中 World Position 节点，或使用节点上的下拉菜单，必须选择：

```text
Absolute World Position (Excluding Material Shader Offsets)
```

不要选择：

```text
Camera Relative World Position (Excluding Material Offsets)
```

Camera Relative 会让世界空间波浪坐标随着相机参考位置变化，可能造成海面图案滑动或跳变。

### 6.3 输入全部连接后仍然报错

1. 双击打开 `MF_OS_WaveSingle`。
2. 确认 `Height`、`SlopeX`、`SlopeY` 三个 Function Output 都有连线。
3. 确认 Sine 和 Cosine 的 Period 都为 `6.283185`。
4. 点击函数窗口顶部 `Apply`，再点击 `Save`。
5. 回到 `M_OS_StylizedOcean`，等待 Shader 编译完成。
6. 点击主材质的 `Apply` 和 `Save`。

### 6.4 出现 `Compilation errors at feature level SM6` 弹窗

这个弹窗只说明编译失败，不会显示具体原因。

1. 点击 `Abort`，不要点击 Continue。
2. 不要勾选 `Don't show this again`。
3. 回到 Material Editor，点击顶部的 `Stats`。
4. 查看底部 `Stats` 面板中的红色 Compiler Error。
5. 如果底部面板没有展开，使用：

```text
Window → Stats
```

也可以打开编辑器底部 `Output Log`，搜索：

```text
Error
```

优先检查 `MF_OS_WaveSingle` 本身：

- `WorldXY` 与 `DirectionXY` 的 Input Type 必须是 Vector2；
- 其余五个 Function Input 必须是 Scalar；
- `Height`、`SlopeX`、`SlopeY` 三个 Function Output 必须都有连线；
- `K` 的 Divide 必须是 `6.283185 / Wavelength`；
- Wavelength 的 Preview Value 不能为 0；
- Sine 和 Cosine 的 Period 都必须是 6.283185；
- 函数内不能遗留红色节点。

修复函数后必须先在函数窗口点击 `Apply`、`Save`，再回到主材质编译。

相加：

```text
TotalHeight = MainHeight + SecondaryHeight
TotalSlopeX = MainSlopeX + SecondarySlopeX
TotalSlopeY = MainSlopeY + SecondarySlopeY
```

创建 Scalar Parameter：

```text
Global_WaveStrength = 1.0
```

先统一计算最终高度与坡度：

```text
FinalHeight = TotalHeight × Global_WaveStrength
FinalSlopeX = TotalSlopeX × Global_WaveStrength
FinalSlopeY = TotalSlopeY × Global_WaveStrength
```

然后为三个最终结果创建 Named Reroute：

```text
NR_WaveHeight
NR_WaveSlopeX
NR_WaveSlopeY
```

`NR_WaveHeight` 对应 FinalHeight，另外两个分别对应 FinalSlopeX、FinalSlopeY。后续 WPO、切色、法线与泡沫都复用这些最终结果，不要重复搭建波浪。碎浪视觉由纹理单独生成，不加入这里的高度和坡度。

## 7. 连接 World Position Offset

第一版只做垂直位移。World Position Offset 需要一个三维向量：

```text
X = 0
Y = 0
Z = NR_WaveHeight
→ World Position Offset
```

### 7.1 使用两个 AppendVector 创建 XYZ

一个 `AppendVector` 只有 A、B 两个输入，所以要使用两个。

1. 在空白处右键，搜索并创建 `Constant`，值设置为 `0`。
2. 创建第一个 `AppendVector`，连接：

```text
Constant 0 → AppendVector_ZeroXY.A
Constant 0 → AppendVector_ZeroXY.B
```

第一个 AppendVector 输出：

```text
(0,0)
```

3. 创建第二个 `AppendVector`，连接：

```text
AppendVector_ZeroXY 输出 → AppendVector_WPO.A
NR_WaveHeight            → AppendVector_WPO.B
```

第二个 AppendVector 输出：

```text
(0,0,WaveHeight)
```

4. 将 `AppendVector_WPO` 输出连接到主材质节点的 `World Position Offset`。

最终结构：

```text
0 ─┐
   ├─ AppendVector ── (0,0) ─┐
0 ─┘                          ├─ AppendVector ─→ World Position Offset
NR_WaveHeight ────────────────┘
```

连接完成后，材质预览球不一定能明显显示大型波浪；必须把材质实例赋给关卡中的 `Ocean_Near` 检查。

### 可选：主浪轻微水平推移

完整 Gerstner 波可增加：

```text
Horizontal = cos(PhaseMain) × MainAmplitude × MainSteepness × MainDirection
```

推荐 `MainSteepness = 0.15–0.30`。第一版不是必须；过强会造成三角形重叠和不自然尖峰。

## 8. 计算世界空间法线

使用已经乘过 `Global_WaveStrength` 的坡度构造：

```text
NormalWS = Normalize(
    AppendVector(
        -NR_WaveSlopeX,
        -NR_WaveSlopeY,
        1
    )
)
```

在节点中：

1. `NR_WaveSlopeX × -1`。
2. `NR_WaveSlopeY × -1`。
3. Append 两者得到 XY。
4. 再 Append 常数 1 得到 XYZ。
5. Normalize。
6. 接入材质 `Normal`。

### 8.1 创建负坡度

1. 创建一个 Constant，值设置为 `-1`。
2. 创建两个 Multiply。
3. 第一个连接：

```text
NR_WaveSlopeX → Multiply_NegX.A
Constant -1  → Multiply_NegX.B
```

得到 `-SlopeX`。

4. 第二个连接：

```text
NR_WaveSlopeY → Multiply_NegY.A
Constant -1  → Multiply_NegY.B
```

得到 `-SlopeY`。

同一个 Constant `-1` 可以同时连接到两个 Multiply。

### 8.2 创建 XY 向量

创建第一个 `AppendVector`：

```text
Multiply_NegX 输出 → Append_NormalXY.A
Multiply_NegY 输出 → Append_NormalXY.B
```

输出为：

```text
(-SlopeX, -SlopeY)
```

### 8.3 添加法线的 Z 分量

1. 创建一个 Constant，值设置为 `1`。
2. 创建第二个 `AppendVector`。
3. 连接：

```text
Append_NormalXY 输出 → Append_NormalXYZ.A
Constant 1           → Append_NormalXYZ.B
```

输出为：

```text
(-SlopeX, -SlopeY, 1)
```

### 8.4 Normalize 并连接 Normal

1. 从 `Append_NormalXYZ` 输出拖线。
2. 搜索并创建 `Normalize`。
3. 把 Normalize 输出连接到主材质节点的 `Normal`。

完整结构：

```text
NR_WaveSlopeX ─→ × -1 ─┐
                        ├→ AppendVector ─┐
NR_WaveSlopeY ─→ × -1 ─┘                 ├→ AppendVector → Normalize → Normal
Constant 1 ──────────────────────────────┘
```

当 `Global_WaveStrength = 0` 时：

```text
SlopeX = 0
SlopeY = 0
NormalWS = Normalize(0,0,1)
```

海面会正确恢复为向上的平面法线。

### 8.5 关闭 Tangent Space Normal

1. 在主材质 Graph 的空白处单击，确保没有选中节点。
2. 在 Details 面板的搜索框输入：

```text
Tangent Space Normal
```

3. 取消勾选 `Tangent Space Normal`。

这里必须关闭，因为当前计算得到的是 World Space Normal。如果保持开启，UE 会把这个数值误认为 Tangent Space Normal，光照方向会错误。

### 8.6 创建 `NR_WaveNormalWS`

Normalize 输出可以先直接连接 Normal。确认编译成功后，在这条线上创建 Named Reroute：

1. 双击 Normalize 到 Normal 之间的连线，创建普通 Reroute。
2. 右键该 Reroute。
3. 选择 `Convert to Named Reroute`。
4. 命名为 `NR_WaveNormalWS`。

如果当前 UE 版本的菜单文字不同，也可以右键 Graph 搜索 `Named Reroute Declaration`，将 Normalize 接入 Declaration，再把对应 Usage 节点接到 Normal。

确认材质已经关闭 `Tangent Space Normal`。

创建 Named Reroute：

`NR_WaveNormalWS`

## 9. 暂时添加调试开关

创建 Static Switch Parameter：

`DEBUG_FreezeWaves`

做法：

```text
False：Time
True：0
```

把结果传给两次 WaveSingle。检查切色、泡沫和截图时可以冻结波浪。

### 9.1 创建 Time 和 Constant 0

1. 在主材质 Graph 空白处右键，搜索并创建 `Time`。
2. 创建一个 Constant，值设置为 `0`。

如果当前 Time 已经直接连接到两个 WaveSingle 的 TimeValue，先断开这两条直接连线。

### 9.2 创建 Static Switch Parameter

1. 在 Graph 空白处右键。
2. 搜索 `Static Switch Parameter`。
3. 创建节点并命名为：

```text
DEBUG_FreezeWaves
```

4. 在 Details 中设置：

```text
Default Value = False
Parameter Group = 09_Debug
```

Default 为 False，表示正常情况下波浪继续播放。

### 9.3 连接 True 和 False

按下面连接：

```text
Time       → DEBUG_FreezeWaves.False
Constant 0 → DEBUG_FreezeWaves.True
```

注意不要接反：

- False：不开启冻结，使用正常 Time；
- True：开启冻结，使用固定的 0。

### 9.4 连接两个波浪函数

把 Static Switch Parameter 的输出同时连接：

```text
DEBUG_FreezeWaves 输出
├─→ Wave_Main.TimeValue
└─→ Wave_Secondary.TimeValue
```

完整结构：

```text
Time ───────→ False ┐
                    ├→ DEBUG_FreezeWaves
Constant 0 ─→ True ─┘
                     ├→ Wave_Main.TimeValue
                     └→ Wave_Secondary.TimeValue
```

### 9.5 在材质实例中使用

打开 `MI_OS_Ocean_Default`：

```text
DEBUG_FreezeWaves = False
```

波浪正常运动。

勾选并设置：

```text
DEBUG_FreezeWaves = True
```

波浪会固定在 Time=0 的形状，方便检查切色、泡沫、接缝和截图。

这是 Static Switch，切换时会重新编译对应材质变体，因此只适合编辑器调试，不适合游戏中频繁实时开关。正式剧情中的 CycleReset 应使用第 07 部分的动态 Scalar/MPC 参数，而不是这个调试开关。

`Global_WaveStrength` 已经在本文件第 6 节计算总波浪结果时创建，不要在这里重复创建。这样在材质实例中调整一次，就会同时影响 WPO、高度切色和世界空间法线。

## 10. 现场调试顺序

1. 先把 Secondary 的 Amplitude 设为 0，只看主浪。
2. 检查一个波长是否正确、移动方向是否正确。
3. 打开 Secondary，确认方向与主浪有明显夹角。
4. 保持 `Detail_Amplitude = 0`。
5. 从玩家常用镜头观察，不要只在材质预览球上判断。
6. Near 使用完整双层 WPO；Far 材质实例在第 06 部分把 `Global_WaveStrength` 设为 0。

## 11. 本部分验收

- [ ] 主浪单独运行时周期正确。
- [ ] 主浪和次浪方向不同，不会同步起伏。
- [ ] 最大总位移约为 400 cm，Bounds 没有裁切。
- [ ] `Detail_Amplitude` 保持为 0，没有短波几何断裂。
- [ ] `Normal` 随波形变化，灯光不会停留在原始平面法线上。
- [ ] `DEBUG_FreezeWaves` 能冻结动画。
- [ ] `Global_WaveStrength = 0` 时海面恢复平面。
- [ ] 材质编译无错误。

## 常见错误

### 波长比设定值短约 6.28 倍

Sine 节点周期单位与公式不一致。按第 3 节重新验证 Period。

### 波面移动速度极快

`Speed` 是相位速度，不是厘米／秒。先把值降低到 0.1–0.7 范围测试。

### 海面只有明暗变化，没有几何起伏

检查网格顶点密度、WPO 连接和 `Global_WaveStrength`。

### 法线方向颠倒

检查 SlopeX、SlopeY 前是否乘以 -1，并确认 Tangent Space Normal 已关闭。
