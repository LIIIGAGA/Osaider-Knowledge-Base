# 第 01 部分：项目准备与海面网格

## 本部分目标

完成后，关卡中应出现一张覆盖宫殿主体的 2 km 近景海面和一张覆盖地平线的 15 km 远景海面。它们暂时可以使用纯色材质，但必须具有正确的 Transform、Bounds 和明确的职责划分。

## 1. 创建资源目录

在 Content Browser 中创建：

```text
Content/Osaider/Ocean/Blueprints
Content/Osaider/Ocean/Materials
Content/Osaider/Ocean/Materials/Functions
Content/Osaider/Ocean/Materials/Instances
Content/Osaider/Ocean/Meshes
Content/Osaider/Ocean/Textures
```

不要把测试材质直接散放在关卡目录。后续 Material Instance、函数和控制 Blueprint 都会互相引用，固定目录可减少丢失引用。

## 2. 导入两张现有纹理

源文件位置：

```text
assets/textures/T_FlowNoise_Large.png
assets/textures/T_FlowNoise_Detail.png
```

导入到：

```text
Content/Osaider/Ocean/Textures
```

导入后分别打开纹理，设置：

### `T_FlowNoise_Large`

- sRGB：关闭。
- Compression Settings：`Masks (no sRGB)`；如果结果出现明显色阶，也可使用 `Grayscale` 对比。
- Texture Group：`World`。
- Address X / Y：`Wrap`。
- Filter：`Default`。
- Mip Gen Settings：`FromTextureGroup`。

### `T_FlowNoise_Detail`

- sRGB：关闭。
- Compression Settings：`Masks (no sRGB)`。
- Texture Group：`World`。
- Address X / Y：`Wrap`。
- Filter：先使用 `Default`，不要一开始改成 Nearest。
- Mip Gen Settings：`Sharpen 2` 可作为后续尝试，第一版先保持默认。

保存后检查：两张纹理都能无缝平铺；Detail 的白色细线在缩小时不会变成整片闪烁噪点。

## 3. 制作近景网格 `SM_Ocean_Near`

### 3.1 当前已经采用的尺寸

当前 Static Mesh 原始数据：

- 网格尺寸：`20000 × 20000 cm`，即 200 × 200 m；
- 分段数量：约 `200 × 200`；
- Actor Scale：`10, 10, 1`；
- 实际覆盖：`200000 × 200000 cm`，即 2 × 2 km；
- 实际顶点间距：约 `1000 cm`，即 10 m。

这个顶点密度不适合 4–30 m 的短几何波，但足够表现 60–200 m 的大尺度波浪。因此后续只使用主浪和次浪做 WPO，小碎浪改由材质纹理表现。

### 3.2 使用 UE Modeling Mode 制作

1. 进入 `Modeling Mode`。
2. 选择 `Shapes > Rectangle` 或 Plane。
3. Width 设置为 `20000`。
4. Height 设置为 `20000`。
5. Width Subdivisions 设置约 `200`。
6. Height Subdivisions 设置约 `200`。
7. 创建到 `Content/Osaider/Ocean/Meshes`。
8. 命名为 `SM_Ocean_Near`。
9. 放入关卡后设置 Actor Scale 为 `10, 10, 1`。

不同版本的 Modeling 工具字段名称可能略有差异；关键是最终尺寸和顶点密度，而不是具体入口名称。

### 3.3 网格设置

打开 Static Mesh：

- Collision Complexity：保持默认，但删除自动复杂碰撞或将 Collision Enabled 设为 No Collision。
- Nanite：第一版关闭。持续 WPO 的大平面不需要依靠 Nanite 获得收益。
- Lightmap：海面不烘焙静态光照，可保持默认但不要为它增加高分辨率 Lightmap。
- Bounds：稍后在 Actor 上调整 `Bounds Scale`。

## 4. 制作远景网格 `SM_Ocean_Far`

远景网格不需要高密度。

当前采用：

- 原始尺寸：`100000 × 100000 cm`，即 1 × 1 km。
- 分段：`20 × 20` 或更低。
- Actor Scale：`15, 15, 1`。
- 实际覆盖：`15 × 15 km`。
- 实际顶点间距：约 `750 m`，因此 Far 不允许使用 WPO。
- 命名：`SM_Ocean_Far`。
- Collision：关闭。
- Nanite：关闭。

远景职责只有：延伸颜色、接住雾、遮住世界空白。它不承担任何几何波峰和高频泡沫。

## 5. 放入测试关卡

在当前测试关卡中：

1. 放置 `SM_Ocean_Near`。
2. 设置 Location 为 `(13970, 17200, -14610)`。
3. 设置 Scale 为 `(10, 10, 1)`。
4. 放置 `SM_Ocean_Far`，X、Y 与 Near 完全一致。
5. 设置 Far Location 为 `(13970, 17200, -14640)`。
6. 设置 Far Scale 为 `(15, 15, 1)`。
7. Far 比 Near 低 30 cm，避免完全共面造成 Z-Fighting。

Actor 命名：

```text
Ocean_Near
Ocean_Far
```

## 6. 设置 Bounds

材质的顶点位移不会自动扩大 Static Mesh 的原始 Bounds。波峰可能因此在镜头边缘突然被裁掉。

选中 `Ocean_Near`：

- Details > Rendering > Bounds Scale：先设为 `1.5`。

完成波浪后再根据最大位移缩小。不要直接设成极大的数值；Bounds 过大会降低剔除效率。

## 7. 碰撞与游戏逻辑约定

WPO 海面只是视觉表面。它的碰撞仍然停留在原始平面上。

第一版建议：

- `Ocean_Near` 与 `Ocean_Far` 都关闭碰撞。
- 如需阻止玩家下落，单独放置一个不可见 Box Collision。
- 如需判断“进入海水”，单独使用 Trigger Volume。
- 如需船体浮力，以平均海平面或独立波浪函数计算，不要读取视觉网格碰撞。

## 8. 临时纯色材质

创建临时材质 `M_OS_Ocean_Blockout`：

- Material Domain：Surface。
- Blend Mode：Opaque。
- Shading Model：Default Lit。
- Base Color：`(0.006, 0.022, 0.032)` 附近的深蓝黑。
- Roughness：`0.45`。
- Metallic：`0`。

把它同时赋给近景和远景。

## 9. 本部分验收

- [ ] 两张 Flow Noise 已导入并关闭 sRGB。
- [ ] `SM_Ocean_Near` 实际覆盖约 2 km，顶点间距约 10 m。
- [ ] `SM_Ocean_Far` 实际覆盖约 15 km。
- [ ] 两张网格都关闭碰撞。
- [ ] Near Scale 为 `10,10,1`，Far Scale 为 `15,15,1`。
- [ ] 近景 Bounds Scale 暂设为 1.5。
- [ ] 远景比近景低 30 cm，没有 Z-Fighting。
- [ ] 测试镜头旋转时看不到近景网格边缘。

## 常见错误

### 后续波浪完全不动

检查波长是否仍沿用旧的小场景参数。当前顶点间距约 10 m，WPO 波长应至少为 60 m；更短的细节应通过法线和泡沫表现。

### 海面偶尔整块消失

通常是 Bounds 太小。先把 `Bounds Scale` 从 1.5 提到 2.0 验证，再精调。

### 玩家站在波峰上却悬空或穿透

这是 WPO 与碰撞不一致的正常结果。视觉海面不应承担精确碰撞。
