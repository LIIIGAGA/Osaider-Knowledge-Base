# 第 07 部分：叙事状态与蓝红污染

## 本部分目标

让海面拥有四种可由剧情控制、可平滑过渡的状态：

```text
Neutral            默认深色机械海
MemoryDisturbance  记忆蓝划痕增加、波浪略活跃
ArchiveControl     宫殿下方出现受控暗红、波浪更规则
CycleReset         海面异常平静，泡沫几乎消失
```

状态不直接切换材质，而是通过 Material Parameter Collection 同时影响近景和远景。

## 1. 创建 Material Parameter Collection

在 `Content/Osaider/Ocean/Materials` 中创建：

`MPC_OS_OceanState`

添加 Scalar Parameter：

| 参数 | 默认值 | 用途 |
|---|---:|---|
| `State_Memory` | 0 | 记忆状态强度 |
| `State_Archive` | 0 | 档案控制强度 |
| `State_Reset` | 0 | 周期重置强度 |
| `State_WaveMultiplier` | 1 | 全局波浪倍率 |
| `State_FoamMultiplier` | 1 | 全局泡沫倍率 |

添加 Vector Parameter：

| 参数 | 默认值 | 用途 |
|---|---|---|
| `State_InfluenceCenter` | `(0,0,0,0)` | 宫殿或事件中心的世界坐标 |

## 2. 在主材质读取 MPC

使用 Collection Parameter 节点读取所有参数。

### 2.1 控制波浪

把第 03 部分的全局波浪倍率改为：

```text
FinalWaveStrength = Global_WaveStrength
                  × State_WaveMultiplier
```

TotalHeight、TotalSlopeX、TotalSlopeY 都乘 `FinalWaveStrength`。

这样 `CycleReset` 不仅压平几何，也同步压平材质法线和切色。

### 2.2 控制泡沫

```text
FinalFoamMask *= State_FoamMultiplier
FinalFoamMask = Saturate(FinalFoamMask)
```

## 3. 制作局部影响范围

为了让档案红只出现在宫殿下方：

1. 获取 `AbsoluteWorldPosition.RG`。
2. 读取 `State_InfluenceCenter.RG`。
3. 使用 Distance。
4. 创建参数：

| 参数 | 默认值 |
|---|---:|
| `Narrative_RadiusInner` | 25000 |
| `Narrative_RadiusOuter` | 90000 |

计算：

```text
LocalInfluence = 1 - SmoothStep(
    Narrative_RadiusInner,
    Narrative_RadiusOuter,
    Distance(WorldXY, InfluenceCenterXY)
)
```

结果：宫殿中心约 250 m 范围接近 1，并在约 900 m 半径处衰减到 0，基本限制在 2 km Near 海面之内。

## 4. MemoryDisturbance 视觉

记忆状态只增强蓝色线索，不把基础海水整体改蓝。

复用第 05 部分的 `DetailLines` 和 `LargeNoise`：

```text
MemoryMask = DetailLines
           × LargeNoise
           × State_Memory
```

创建 Scalar Parameter：

| 参数 | 默认值 |
|---|---:|
| `Memory_ColorStrength` | 0.32 |
| `Memory_EmissiveStrength` | 0.04 |

混合：

```text
MemoryBlend = Saturate(MemoryMask × Memory_ColorStrength)
ColorAfterMemory = Lerp(OceanWithFoam, Color_Memory, MemoryBlend)
```

极弱 Emissive：

```text
MemoryEmissive = Color_Memory
               × MemoryMask
               × Memory_EmissiveStrength
```

默认 Memory 状态下，明显蓝线覆盖海面可见面积应低于约 8%。

## 5. ArchiveControl 视觉

档案状态使用局部暗红污染：

```text
ArchiveMask = LocalInfluence
            × LargeNoise
            × State_Archive
```

创建：

| 参数 | 默认值 |
|---|---:|
| `Archive_ColorStrength` | 0.28 |
| `Archive_PulseStrength` | 0.08 |
| `Archive_PulseSpeed` | 0.18 |

可选的缓慢脉冲：

```text
Pulse = sin(Time × Archive_PulseSpeed) × 0.5 + 0.5
ArchiveFinal = ArchiveMask
             × (Archive_ColorStrength + Pulse × Archive_PulseStrength)
```

混合：

```text
ColorAfterArchive = Lerp(
    ColorAfterMemory,
    Color_Archive,
    Saturate(ArchiveFinal)
)
```

不要给档案红使用明显 Emissive。它应像水下炉火、油污或制度渗漏，不是红色警报灯。

## 6. CycleReset 视觉

Reset 状态主要由 Blueprint 调低：

```text
State_WaveMultiplier = 0.05–0.12
State_FoamMultiplier = 0.05–0.15
```

材质中可额外加入非常轻的去饱和：

```text
ResetGray = Desaturation(CurrentColor, 0.35)
FinalColor = Lerp(CurrentColor, ResetGray, State_Reset × 0.45)
```

这种“突然过于平静”比新增大量特效更符合循环重置的压迫感。

## 7. 最终颜色与 Emissive 顺序

建议固定顺序：

```text
三段海面切色
→ 泡沫
→ Memory 蓝色细线
→ Archive 局部暗红
→ Reset 去饱和
→ 距离颜色融合
→ Base Color
```

Emissive 只允许：

```text
MemoryEmissive + 极弱泡沫补偿
```

并限制在很低强度。

## 8. 创建状态枚举

在 Content Browser 创建 Blueprint Enumeration：

`E_OS_OceanState`

值：

```text
Neutral
MemoryDisturbance
ArchiveControl
CycleReset
```

## 9. 创建 `BP_OS_OceanController`

在 `Content/Osaider/Ocean/Blueprints` 创建 Actor Blueprint：

`BP_OS_OceanController`

组件：

```text
DefaultSceneRoot
└─ Billboard（可选，只用于编辑器定位）
```

变量：

| 变量 | 类型 | 默认值 |
|---|---|---:|
| `CurrentState` | `E_OS_OceanState` | Neutral |
| `TransitionDuration` | Float | 2.5 |
| `StartMemory` | Float | 0 |
| `StartArchive` | Float | 0 |
| `StartReset` | Float | 0 |
| `StartWave` | Float | 1 |
| `StartFoam` | Float | 1 |
| `TargetMemory` | Float | 0 |
| `TargetArchive` | Float | 0 |
| `TargetReset` | Float | 0 |
| `TargetWave` | Float | 1 |
| `TargetFoam` | Float | 1 |

把 Actor 放在宫殿中心或希望红色污染出现的中心。

## 10. BeginPlay 初始化

在 BeginPlay：

```text
GetActorLocation
→ Set Vector Parameter Value
   Collection = MPC_OS_OceanState
   Parameter Name = State_InfluenceCenter

→ ApplyOceanState(Neutral, false)
```

如果宫殿会移动，定期更新 InfluenceCenter；静态宫殿只需 BeginPlay 设置一次。

## 11. 创建过渡 Timeline

创建 Timeline：

`TL_OceanStateTransition`

添加 Float Track：

`Alpha`

关键帧：

```text
Time 0.0 → Value 0.0
Time 1.0 → Value 1.0
```

曲线使用 Ease In Out。Timeline 长度固定为 1 秒，通过 `Set Play Rate = 1 / TransitionDuration` 控制实际时长。

### Timeline Update

每次 Update：

```text
Lerp(StartMemory,  TargetMemory,  Alpha) → Set MPC State_Memory
Lerp(StartArchive, TargetArchive, Alpha) → Set MPC State_Archive
Lerp(StartReset,   TargetReset,   Alpha) → Set MPC State_Reset
Lerp(StartWave,    TargetWave,    Alpha) → Set MPC State_WaveMultiplier
Lerp(StartFoam,    TargetFoam,    Alpha) → Set MPC State_FoamMultiplier
```

## 12. 创建 `ApplyOceanState`

创建 Function 或 Custom Event：

```text
ApplyOceanState(NewState, bUseTransition)
```

先读取 MPC 当前值，保存到所有 `Start...` 变量。这样中途切换状态也不会跳变。

使用 `Switch on E_OS_OceanState` 设置目标值：

| 状态 | Memory | Archive | Reset | Wave | Foam |
|---|---:|---:|---:|---:|---:|
| Neutral | 0.00 | 0.00 | 0.00 | 1.00 | 1.00 |
| MemoryDisturbance | 0.55 | 0.00 | 0.00 | 1.12 | 1.20 |
| ArchiveControl | 0.00 | 0.48 | 0.00 | 0.82 | 0.78 |
| CycleReset | 0.00 | 0.00 | 1.00 | 0.08 | 0.10 |

然后：

```text
bUseTransition = true
→ Set Play Rate(1 / Max(TransitionDuration, 0.01))
→ Play From Start TL_OceanStateTransition

bUseTransition = false
→ 直接把 Target 值写入 MPC
```

最后设置 `CurrentState = NewState`。

## 13. 调试入口

施工期间可在 Level Blueprint 或 PlayerController 临时绑定：

```text
F5 → Neutral
F6 → MemoryDisturbance
F7 → ArchiveControl
F8 → CycleReset
```

每次调用：

```text
GetActorOfClass BP_OS_OceanController
→ ApplyOceanState(目标状态, true)
```

正式版本移除或禁用这些调试按键。

## 14. 本部分验收

- [ ] 近景和远景同时响应 MPC。
- [ ] 四种状态都能通过调试入口触发。
- [ ] 状态转换持续约 2.5 秒，没有瞬间跳变。
- [ ] 转换中途切换另一状态仍然连续。
- [ ] Memory 蓝线覆盖面积保持克制。
- [ ] Archive 红色主要局限于 InfluenceCenter 附近。
- [ ] CycleReset 会同时压低几何波浪、法线坡度和泡沫。
- [ ] Neutral 能完整恢复默认值。

## 常见错误

### 状态只影响近景，不影响远景

确认两个材质实例都使用读取 `MPC_OS_OceanState` 的同一个主材质。

### 中途切状态出现跳变

每次 Apply 前必须读取 MPC 的当前值作为 Start，不能假设 Start 是上一个状态的固定目标值。

### Reset 后颜色恢复但波面仍然很陡

SlopeX、SlopeY 必须和 Height 一起乘 `State_WaveMultiplier`。

### 红色覆盖整片海

检查 `LocalInfluence` 是否反相正确、InfluenceCenter 是否在宫殿位置、RadiusOuter 是否过大。
