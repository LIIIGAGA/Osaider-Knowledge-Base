# 第 04 部分：低多边形三段切色

## 本部分目标

让海面即使完全关闭泡沫，也能表现出明确的低多边形块面。颜色只使用少量离散层级，不追求连续、写实的明暗渐变。

## 1. 切色所需输入

复用第 03 部分：

```text
NR_WaveHeight
NR_WaveNormalWS
```

再创建 Vector Parameter：

`GraphicLightDirection = (-0.45, -0.35, 0.82)`

它是材质内部用于风格化切色的固定方向，不必与真实 Directional Light 完全一致。Normalize 后使用。

这样可以让色块构图保持稳定，不会因 Lumen 或场景灯光小幅变化而不断抖动。

## 2. 计算波浪高度归一化值

创建 Scalar Parameter：

| 参数 | 默认值 |
|---|---:|
| `Height_Min` | -400 |
| `Height_Max` | 400 |

计算：

```text
Height01 = Saturate(
    (WaveHeight - Height_Min)
    / (Height_Max - Height_Min)
)
```

如果后续改变主浪和次浪 Amplitude，应同步检查 Height_Min/Max。当前 `300 + 100 cm` 的理论最大绝对高度约为 400 cm。

## 3. 计算图形化受光值

```text
NdotGraphicLight = Saturate(
    Dot(NR_WaveNormalWS, Normalize(GraphicLightDirection))
)
```

组合高度和朝向：

```text
BandInput = Height01 × Height_Influence
          + NdotGraphicLight × Light_Influence
```

创建参数：

| 参数 | 默认值 |
|---|---:|
| `Height_Influence` | 0.62 |
| `Light_Influence` | 0.38 |

两者总和保持约 1，方便理解阈值。

## 4. 创建两个硬阈值

创建：

| 参数 | 默认值 |
|---|---:|
| `Band_MidThreshold` | 0.43 |
| `Band_CrestThreshold` | 0.68 |

使用两个 `If` 节点：

```text
MidMask:
A = BandInput
B = Band_MidThreshold
A >= B 输出 1
A < B 输出 0

CrestMask:
A = BandInput
B = Band_CrestThreshold
A >= B 输出 1
A < B 输出 0
```

如果版本中 `Step` 节点可用，也可以用 Step。重点是得到 0 或 1 的硬遮罩。

## 5. 三段颜色混合

按顺序：

```text
DeepToMid = Lerp(Color_Deep, Color_Mid, MidMask)
BandColor = Lerp(DeepToMid, Color_Crest, CrestMask)
```

把 `BandColor` 暂时接到 Base Color。

不要先做很多渐变。第一轮检查时应该能清楚看见三档颜色区域。

## 6. 打散机械等高线

纯高度阈值容易产生过于整齐的平行色带。复用 `T_FlowNoise_Large`：

1. 获取 `AbsoluteWorldPosition.RG`。
2. 除以 `ColorNoise_WorldScale`，默认 `40000`。
3. 采样 `T_FlowNoise_Large` 的 R 通道。
4. 转成以 0 为中心：`NoiseCentered = Noise × 2 - 1`。
5. 乘 `ColorNoise_Strength = 0.06`。
6. 在进入阈值前加到 `BandInput`。

```text
BandInputNoisy = BandInput + NoiseCentered × ColorNoise_Strength
```

噪声强度保持很低。它只负责在公里级海面上打破完全规则的色带，不应盖过两层几何波浪结构。

## 7. 可选：降低颜色跳变闪烁

硬阈值在远处可能闪烁。优先顺序：

1. 保留硬切色，先看目标分辨率是否真的明显。
2. 若闪烁，仅给阈值加入 `0.01–0.03` 的极窄 SmoothStep。
3. 不要直接改成宽范围渐变。

例如：

```text
SmoothStep(
    Threshold - 0.015,
    Threshold + 0.015,
    BandInput
)
```

## 8. 重新加入轻微 Fresnel

第 02 部分的 Fresnel 改为：

```text
FinalBaseColor = BandColor
               + Fresnel × Fresnel_Strength × Color_Mid
```

建议：

- `Fresnel_Strength = 0.04–0.08`。
- 不使用白色 Fresnel。
- 地平线附近仍应保持深色。

## 9. 表面参数微调

推荐起点：

```text
Roughness = 0.42
Specular  = 0.28
Metallic  = 0
```

如果真实灯光高光破坏了三段色块：

- 先提高 Roughness 到 0.50；
- 再降低 Specular；
- 不要用高 Emissive 强行压住灯光。

## 10. 低多边形感不足时的处理顺序

按顺序调整：

1. 拉大主浪和次浪的波长差异。
2. 增加 `Band_MidThreshold` 与 `Band_CrestThreshold` 之间的距离。
3. 降低 Fresnel 与真实高光。
4. 调整 `GraphicLightDirection` 形成斜向块面。
5. 最后才考虑换成更粗的三角网格。

不要用强烈低分辨率法线贴图模拟低多边形，它通常会产生塑料水晶感。

## 11. 本部分验收

- [ ] 关闭泡沫时仍能看见明确的三段色块。
- [ ] 深色区域占据最大面积。
- [ ] `Color_Crest` 只出现在部分高处／朝光面。
- [ ] 色块边缘总体清晰，远处没有严重闪烁。
- [ ] Fresnel 没有形成白色塑料边。
- [ ] 真实灯光高光不会盖过图形化切色。
- [ ] 固定镜头截图与项目现有低多边形建筑放在一起时不显得写实。

## 常见错误

### 整片海都变成 Crest 色

降低 BandInput、提高 `Band_CrestThreshold`，并检查 GraphicLightDirection 是否归一化。

### 色带像地形等高线

提高朝向影响、降低高度影响，并加入极弱的 Large Noise 偏移。

### 画面像发光霓虹水

降低颜色饱和度和 Emissive。记忆蓝应该是受控的叙事痕迹，不是默认霓虹灯。
