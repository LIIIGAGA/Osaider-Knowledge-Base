# 第 05 部分：流动泡沫与档案划痕

## 本部分目标

使用项目已有的两张纹理制作两类泡沫：

1. 波峰附近的旧纸状碎片泡沫；
2. 沿海面运动的横向档案划痕。

泡沫必须稀疏、硬边、方向明确，不能覆盖整片海面。

本部分参数已经按 Near 的 2 km 实际覆盖调整。所有纹理都使用世界空间坐标，因此 Actor Scale 为 10 时不会把纹理跟着拉伸；不要改回模型 UV。

## 1. 创建纹理参数

在主材质中创建 Texture Object Parameter 或 Texture Sample Parameter 2D：

| 参数名 | 默认纹理 |
|---|---|
| `Tex_FlowLarge` | `T_FlowNoise_Large` |
| `Tex_FlowDetail` | `T_FlowNoise_Detail` |

如果使用 Material Function，Texture Object Parameter 更方便传入函数；如果直接在主材质完成，Texture Sample Parameter 2D 即可。

## 2. 创建世界空间 UV

不要直接使用模型 UV 作为主要流动坐标，避免近景和远景网格尺度变化后纹理密度不同。

获取：

```text
Absolute World Position (Excluding Material Shader Offsets)
→ ComponentMask RG
→ WorldXY
```

### Large UV

参数：

| 参数 | 默认值 |
|---|---:|
| `FoamLarge_WorldScale` | 50000 |
| `FoamLarge_SpeedX` | 0.004 |
| `FoamLarge_SpeedY` | -0.002 |

计算：

```text
LargeUV = WorldXY / FoamLarge_WorldScale
        + Time × (FoamLarge_SpeedX, FoamLarge_SpeedY)
```

采样 `Tex_FlowLarge.R`，得到 `LargeNoiseA`。

再制作第二次采样，避免整张纹理像贴纸移动：

```text
LargeUV_B = WorldXY / (FoamLarge_WorldScale × 0.73)
          + Time × (-FoamLarge_SpeedY, FoamLarge_SpeedX × 1.2)
          + (0.31, 0.67)
```

得到 `LargeNoiseB`。

组合：

```text
LargeNoise = Saturate(LargeNoiseA × 0.65 + LargeNoiseB × 0.55)
```

## 3. 生成波峰遮罩

复用第 04 部分的 `Height01`。

创建参数：

| 参数 | 默认值 |
|---|---:|
| `Foam_CrestStart` | 0.69 |
| `Foam_CrestNoise` | 0.15 |

先用噪声扰动阈值：

```text
DynamicCrestThreshold = Foam_CrestStart
                      + (LargeNoise - 0.5) × Foam_CrestNoise
```

再用 `If`：

```text
Height01 >= DynamicCrestThreshold → 1
否则 → 0
```

得到 `CrestFoamMask`。

## 4. 生成陡坡遮罩

复用 `NR_WaveNormalWS` 的 Z：

```text
Steepness = 1 - Saturate(NormalWS.Z)
```

参数：

| 参数 | 默认值 |
|---|---:|
| `Foam_SlopeStart` | 0.008 |
| `Foam_SlopeStrength` | 0.45 |

使用 If 或窄 SmoothStep：

```text
SlopeMask = Step(Foam_SlopeStart, Steepness)
          × Foam_SlopeStrength
```

坡度遮罩不能单独覆盖整片海。它必须再乘以 LargeNoise，并且权重低于波峰泡沫。

## 5. 合并大形泡沫

```text
FoamShape = Saturate(
    Max(CrestFoamMask, SlopeMask)
    × LargeNoise
)
```

为了保持硬边，再创建：

| 参数 | 默认值 |
|---|---:|
| `Foam_ShapeThreshold` | 0.48 |

```text
FoamHard = Step(Foam_ShapeThreshold, FoamShape)
```

如果 Step 造成远景闪烁，使用宽度不超过 0.03 的 SmoothStep。

## 6. 添加档案划痕细节

Detail 纹理本身包含大量横向白色细线。它应作为泡沫内部的“纤维／划痕”，而不是铺满整个海面。

参数：

| 参数 | 默认值 |
|---|---:|
| `FoamDetail_WorldScaleX` | 12000 |
| `FoamDetail_WorldScaleY` | 6000 |
| `FoamDetail_SpeedX` | 0.012 |
| `FoamDetail_SpeedY` | 0.0015 |
| `FoamDetail_Threshold` | 0.62 |

计算非等比 UV：

```text
DetailUV.X = WorldX / FoamDetail_WorldScaleX
DetailUV.Y = WorldY / FoamDetail_WorldScaleY
DetailUV += Time × (FoamDetail_SpeedX, FoamDetail_SpeedY)
```

采样 `Tex_FlowDetail.R`：

```text
DetailLines = Step(FoamDetail_Threshold, DetailSample)
```

只保留泡沫区域：

```text
DetailInsideFoam = DetailLines × Saturate(FoamHard + CrestFoamMask)
```

## 7. 合并最终泡沫遮罩

创建参数：

| 参数 | 默认值 |
|---|---:|
| `Foam_BaseOpacity` | 0.72 |
| `Foam_DetailStrength` | 0.55 |

```text
FinalFoamMask = Saturate(
    FoamHard × Foam_BaseOpacity
    + DetailInsideFoam × Foam_DetailStrength
)
```

颜色混合：

```text
OceanWithFoam = Lerp(
    FinalBaseColor,
    Color_Foam,
    FinalFoamMask
)
```

接到 Base Color。

## 8. 泡沫表面响应

泡沫处应更粗糙：

```text
FoamRoughness = 0.72
FinalRoughness = Lerp(
    Surface_Roughness,
    FoamRoughness,
    FinalFoamMask
)
```

把 `FinalRoughness` 接到 Roughness。

泡沫不需要强 Emissive。若夜景中完全不可读，可使用：

```text
Color_Foam × FinalFoamMask × 0.02–0.05
```

作为极弱 Emissive，且只在最终曝光确认后开启。

## 9. 控制泡沫覆盖率

从俯视截图检查。默认状态建议：

- 明显泡沫覆盖画面海面面积的约 5%–12%；
- Detail 细线覆盖约 2%–6%；
- 不出现完整重复的方形纹理块；
- 宫殿附近可以略多，地平线附近应逐渐减少。

如果覆盖过多，按以下顺序调整：

1. 提高 `Foam_CrestStart`；
2. 提高 `Foam_ShapeThreshold`；
3. 提高 `FoamDetail_Threshold`；
4. 最后才降低颜色亮度。

不要只把泡沫颜色调暗来掩盖覆盖率问题。

## 10. 远距离淡出 Detail

细线在远距离会产生摩尔纹。使用 Camera Position 与 Absolute World Position 计算距离：

参数：

| 参数 | 默认值 |
|---|---:|
| `FoamDetail_FadeStart` | 50000 |
| `FoamDetail_FadeEnd` | 100000 |

```text
DistanceFade = 1 - Saturate(
    (CameraDistance - FadeStart)
    / (FadeEnd - FadeStart)
)

DetailInsideFoam *= DistanceFade
```

大形泡沫可以保留，只有高频 Detail 需要淡出。

## 11. 本部分验收

- [ ] Large Noise 以世界空间平铺，海面缩放不会改变纹理密度。
- [ ] 泡沫主要出现在波峰与少量陡坡。
- [ ] Detail 划痕只存在于局部泡沫中。
- [ ] 两组噪声速度和方向不同，没有整张贴纸移动感。
- [ ] 默认泡沫覆盖率约 5%–12%。
- [ ] 远处 Detail 会淡出，不产生严重摩尔纹。
- [ ] 泡沫比海水更粗糙，但不明显发光。

## 常见错误

### 泡沫纹理看起来固定在模型上

确认使用 Absolute World Position，而不是 Texture Coordinate。

### 泡沫与波峰对不上

确认泡沫高度使用与 WPO 相同的 `NR_WaveHeight`，不要重复一套速度或相位不同的波浪计算。

### 整片海面像电视雪花

Detail 没有乘大形泡沫遮罩，或远距离淡出没有生效。

### 细线方向太整齐

旋转第二次 Detail UV 约 15–25 度，或以低强度 Large Noise 扰动 UV。不要增加更多高频纹理层。
