# 第 08 部分：测试、优化与排错

## 本部分目标

在交付前验证风格、稳定性和性能，处理 WPO Bounds、纹理闪烁、远景接缝、状态残留等问题。

不要只在材质预览窗口验收。所有检查都必须回到目标关卡、目标镜头和目标曝光中进行。

开始测试前确认当前场景基准：

```text
Near Location = (13970, 17200, -14610)
Near Scale = (10, 10, 1)
Near 实际范围 = 2 × 2 km

Far Location = (13970, 17200, -14640)
Far Scale = (15, 15, 1)
Far 实际范围 = 15 × 15 km
```

## 1. 建立测试矩阵

至少测试以下镜头：

| 镜头 | 主要检查内容 |
|---|---|
| 玩家常规镜头 | 整体风格、宫殿层次、海面抢戏程度 |
| 低位贴近海面 | 顶点密度、WPO 形状、泡沫边缘 |
| 高位俯视 | 纹理重复、泡沫覆盖率、方形边缘 |
| 朝向地平线 | Fresnel、远景接缝、海天线 |
| 宫殿正下方 | Archive 红色范围、局部锚点 |

测试分辨率：

- 1920 × 1080；
- 1600 × 900；
- 2560 × 1440；
- 实际计划发布的最低分辨率。

## 2. 分层关闭检查

按以下顺序在 `MI_OS_Ocean_Default` 中检查：

### 2.1 只看主浪

```text
Secondary_Amplitude = 0
Detail_Amplitude = 0
Foam_BaseOpacity = 0
Foam_DetailStrength = 0
```

确认主浪周期、方向和 Bounds 正确。

### 2.2 打开次浪

确认不会与主浪同方向同步移动，也不会形成规则棋盘格。

### 2.3 确认碎浪几何保持关闭

确认 `Detail_Amplitude = 0`。当前 Near 顶点间距约 10 m，不允许重新打开短波 WPO。小尺度动态只检查第 05 部分的泡沫和划痕纹理。

### 2.4 打开三段切色

冻结波浪截图，确认深、中、峰三段比例。

### 2.5 最后打开泡沫

泡沫是最后一层，不应被用来掩盖波浪或切色本身的问题。

## 3. 风格验收

与项目现有低多边形建筑同屏检查：

- 海面是否仍然比建筑更写实？
- 是否出现清晰天空镜像？
- 是否有大量连续柔和渐变？
- 泡沫是否像摄影浪花，而不是图形划痕？
- 红蓝是否变成普通装饰色，而非叙事信号？

如果答案为“是”，优先处理：

1. 降低 Fresnel 和 Specular；
2. 提高 Roughness；
3. 收窄色带过渡；
4. 减少泡沫覆盖；
5. 降低蓝色和红色默认强度。

## 4. Bounds 与剔除测试

在波浪最大振幅下：

1. 把相机移动到海面边缘附近。
2. 上下转动镜头。
3. 快速横向移动。
4. 观察海面或波峰是否突然消失。

如果消失：

- 检查 `Ocean_Near.Bounds Scale`；
- 从 1.2、1.5、2.0 逐步提高；
- 只设到稳定所需的最小值；
- 确认最大总振幅没有超过文档记录。

## 5. 纹理重复测试

从高位俯视，冻结波浪：

- 查找重复的方形、十字或明显旋涡；
- 检查两次 Large Noise 是否使用不同尺度、偏移和方向；
- 检查 Detail 是否只在泡沫内部出现；
- 不要通过增加第三、第四张高频纹理解决重复。

优先使用：双采样、不同尺度、旋转 UV、世界空间偏移。

## 6. 闪烁与摩尔纹

如果移动镜头时远处细线闪烁：

1. 确认纹理有正常 Mip Map。
2. 不要使用 Nearest Filter。
3. 提前 `FoamDetail_FadeStart`。
4. 降低 Detail 对比度或提高阈值。
5. 将硬 Step 换成宽度 0.01–0.03 的 SmoothStep。
6. 仍然严重时，远景实例彻底关闭 Detail。

不要用 Temporal AA 的拖影来掩盖材质闪烁。

## 7. Shader Complexity 检查

在编辑器 View Mode 中切换：

```text
Optimization Viewmodes > Shader Complexity
```

检查：

- 海面是否明显比周围普通材质成本高很多；
- 远景材质是否仍执行不需要的 Detail 纹理采样；
- 是否存在不必要的透明 Overdraw；
- 两层波函数是否被重复计算多次。

优化顺序：

1. 确保波浪结果使用 Named Reroute 复用。
2. 远景通过 Static Switch 关闭 Detail Foam。
3. 移除没有视觉贡献的额外纹理采样。
4. 确认没有第三层碎浪 WPO，只保留纹理颜色／泡沫贡献。
5. 最后才降低近景网格密度。

## 8. 创建质量开关

在主材质创建 Static Switch Parameter：

```text
QUALITY_UseDetailWave
QUALITY_UseDetailFoam
QUALITY_UseNarrativePulse
QUALITY_UseGeometricWaves
```

建议实例：

### Near

```text
UseDetailWave = false
UseDetailFoam = true
UseNarrativePulse = true
UseGeometricWaves = true
```

### Far

```text
UseDetailWave = false
UseDetailFoam = false
UseNarrativePulse = false
UseGeometricWaves = false
```

当前项目中 `UseDetailWave` 即使在 Near 也保持 `false`；这里的 Detail 指短波几何，不影响泡沫纹理细节。

Static Switch 会生成不同 Shader permutation，不要创建大量组合。只保留近景和远景真正需要的两套。

## 9. 状态循环测试

连续执行：

```text
Neutral
→ MemoryDisturbance
→ ArchiveControl
→ CycleReset
→ Neutral
```

每种状态等待过渡完成，再执行下一种。然后在过渡进行到一半时快速切换。

检查：

- 没有颜色瞬跳；
- 没有 Timeline 卡住；
- Neutral 能恢复 Wave = 1、Foam = 1；
- Reset 后法线与泡沫都恢复；
- Memory 与 Archive 不会同时残留在非预期状态；
- InfluenceCenter 正确跟随宫殿位置。

## 10. 常见问题总表

| 问题 | 最可能原因 | 处理 |
|---|---|---|
| 波浪不动 | WPO 未连接、Global Strength 为 0 | Near 检查材质输出和实例参数；Far 保持不动是正确结果 |
| 波浪断成大块 | 波长仍使用旧的 28 m／11 m 数值 | 改为 Main 200 m、Secondary 70 m，Detail WPO 关闭 |
| 波浪周期错误 | Sine Period 与 2PI 公式不一致 | 用一个 Wavelength 实测一次完整周期 |
| 波峰被裁掉 | Bounds 太小 | 提高 Bounds Scale |
| 光照像平面 | 没有把坡度法线接到 Normal | 检查世界空间法线和 Tangent Space Normal |
| 色块全是 Crest | 阈值太低或方向未归一化 | 提高 CrestThreshold，Normalize 方向 |
| 泡沫铺满海面 | 遮罩未乘 LargeNoise 或阈值过低 | 提高阈值并检查乘法顺序 |
| 远处闪烁 | Detail 过密或无距离淡出 | 启用 Mip、距离淡出、关闭远景 Detail |
| 接缝闪烁 | 近远景共面 | 远景下移或制作环形网格 |
| 海面像塑料 | Fresnel／Specular 太强 | 降低二者，提高 Roughness |
| 红海覆盖过大 | 局部距离遮罩反相或半径过大 | 检查 LocalInfluence 和中心坐标 |
| Reset 后仍有起伏光照 | 只缩放了 WPO | Height 与 Slope 同时乘状态倍率 |
| 玩家碰撞不跟波浪 | WPO 不改变碰撞 | 使用独立逻辑平面或波函数 |

## 12. 最终验收清单

### 几何与动画

- [ ] 两层大尺度波浪周期、方向和速度符合设计。
- [ ] 碎浪几何位移保持关闭。
- [ ] 海面边缘和波峰不会被错误裁切。
- [ ] 视觉网格不承担精确碰撞。

### 材质风格

- [ ] 默认画面约 80% 保持深色中性。
- [ ] 三段切色清晰但远处稳定。
- [ ] 泡沫覆盖率受控，像档案划痕而非写实浪花。
- [ ] 无明显透明、折射或镜面倒影。

### 场景整合

- [ ] 近远景无明显接缝。
- [ ] 海天线被雾与距离颜色自然隐藏。
- [ ] 宫殿仍然是画面第一视觉中心。
- [ ] 红蓝状态不会削弱阵营色的叙事意义。

### 性能与稳定性

- [ ] 目标最低分辨率无严重闪烁。
- [ ] 远景关闭不必要的 Detail 波浪和泡沫。
- [ ] Shader Complexity 在项目预算内。
- [ ] 四种状态连续循环不会残留错误参数。
- [ ] 正式版本已移除 F5–F8 调试输入或限制为开发构建。
