# 第 02 部分：主材质与参数框架

## 本部分目标

创建主材质 `M_OS_StylizedOcean` 和材质实例 `MI_OS_Ocean_Default`。本部分先完成稳定的深色海面、参数分类和世界空间法线设置，不加入波浪与泡沫。

## 1. 创建主材质

在 `Content/Osaider/Ocean/Materials` 中创建 Material：

`M_OS_StylizedOcean`

打开材质并设置：

- Material Domain：`Surface`
- Blend Mode：`Opaque`
- Shading Model：`Default Lit`
- Two Sided：关闭
- Use Material Attributes：关闭，第一版直接连接主节点
- Tangent Space Normal：关闭

关闭 `Tangent Space Normal` 很重要：第 03 部分会计算世界空间波浪法线，并直接接入 `Normal`。

## 2. 为什么使用 Opaque

当前项目的建筑、UI 和道具语言都强调：

- 明确块面；
- 黑色负空间；
- 高饱和局部强调；
- 舞台模型感；
- 机械与档案材质。

透明水体常见的折射、Scene Color、深度吸收和高亮反射会把风格拉向写实。`Opaque` 还能避免大面积透明排序和过度绘制问题。

## 3. 创建基础颜色参数

依次创建 Vector Parameter：

| 参数名 | 默认值（Hex） | 用途 |
|---|---:|---|
| `Color_Deep` | `#06131A` | 大面积深色基底 |
| `Color_Mid` | `#123742` | 朝光或中等高度块面 |
| `Color_Crest` | `#24677A` | 波峰记忆蓝 |
| `Color_Foam` | `#C8C0A8` | 旧纸灰黄泡沫 |
| `Color_Archive` | `#7A1E1E` | 档案红污染 |
| `Color_Memory` | `#1A4A68` | 记忆蓝污染 |

UE 颜色选择器中的显示结果会受 ACES 和曝光影响。不要只照抄数值，最终应在目标 Post Process 下微调。

## 4. 创建表面参数

创建 Scalar Parameter：

| 参数名 | 默认值 | 建议范围 |
|---|---:|---:|
| `Surface_Roughness` | `0.42` | 0.30–0.55 |
| `Surface_Specular` | `0.28` | 0.15–0.40 |
| `Fresnel_Power` | `5.0` | 3.0–8.0 |
| `Fresnel_Strength` | `0.08` | 0.00–0.15 |
| `Ocean_EmissiveStrength` | `0.0` | 0.00–0.15 |

连接：

```text
Surface_Roughness → Roughness
Surface_Specular  → Specular
0                 → Metallic
```

不要把海面做成 Metallic。氧化金属属于宫殿和界面框架，不属于海水本身。

## 5. 建立基础颜色输出

暂时直接连接：

```text
Color_Deep → Base Color
```

如果测试关卡太暗，可以临时连接：

```text
Color_Deep × Ocean_EmissiveStrength → Emissive Color
```

`Ocean_EmissiveStrength` 默认保持 0。它只用于调试和极弱的可读性补偿，不应让海水自己发光。

## 6. 添加轻微 Fresnel

创建 `Fresnel` 节点：

- ExponentIn：`Fresnel_Power`
- BaseReflectFractionIn：使用默认或很低的数值

计算：

```text
FresnelTint = Fresnel × Fresnel_Strength
BaseWithFresnel = Color_Deep + FresnelTint × Color_Mid
```

暂时将 `BaseWithFresnel` 接到 Base Color。

目标：只有接近地平线的掠射角略微变亮，不能出现明亮塑料边缘。

## 7. 参数分组

为便于材质实例调整，给参数设置 Group：

```text
01_Palette
02_Surface
03_Waves_Main
04_Waves_Secondary
05_Waves_Detail
06_ColorBands
07_Foam
08_Narrative
09_Debug
```

本部分创建的颜色进入 `01_Palette`，表面参数进入 `02_Surface`。

## 8. 创建材质实例

右键 `M_OS_StylizedOcean`，创建 Material Instance：

`MI_OS_Ocean_Default`

保存到：

`Content/Osaider/Ocean/Materials/Instances`

把实例赋给 `Ocean_Near`。远景暂时继续使用 Blockout 材质，直到第 06 部分。

## 9. 检查曝光

在测试关卡中锁定曝光，避免材质调试时画面自动变亮或变暗：

1. 放置或找到 Post Process Volume。
2. 勾选 Infinite Extent (Unbound)。
3. Exposure 使用当前项目最终方案。
4. 如果项目尚未确定曝光，调试阶段先固定 Min EV100 和 Max EV100 为相同值。

记录所用曝光数值。否则后续每次判断海面颜色都会被自动曝光干扰。

## 10. 本部分验收

- [ ] 主材质为 Opaque / Default Lit。
- [ ] `Tangent Space Normal` 已关闭。
- [ ] 颜色与表面参数已按 Group 分类。
- [ ] 材质实例已赋给近景海面。
- [ ] 海面在目标曝光下接近深蓝黑，而不是纯黑洞。
- [ ] 掠射角只有轻微提亮。
- [ ] 材质无编译错误。

## 常见错误

### 颜色选择器数值正确，但画面过亮

检查自动曝光、Directional Light、Sky Light 和 Post Process，而不是立即把所有颜色压成纯黑。

### Fresnel 像一圈白色塑料边

降低 `Fresnel_Strength`，并用 `Color_Mid` 对 Fresnel 染色，不要直接加纯白。

### 后续接入世界空间法线后方向错误

确认材质属性 `Tangent Space Normal` 已关闭。
