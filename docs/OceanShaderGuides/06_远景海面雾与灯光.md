# 第 06 部分：远景海面、雾与灯光

## 本部分目标

完成近景与远景海面的衔接，隐藏方形边缘和清晰海天线，并建立适合 Osaider 的低照度灯光关系。

最终画面重点应是浮空宫殿；海面负责制造尺度、深度和不安感，不抢夺主体。

当前 Near 实际覆盖 2 km，Far 实际覆盖 15 km。Far 的实际顶点间距非常大，因此远景禁止几何位移，只使用颜色、Fresnel、距离融合和雾。

## 1. 创建远景材质实例

复制 `MI_OS_Ocean_Default`：

`MI_OS_Ocean_Far`

建议覆盖参数：

| 参数 | 近景 | 远景 |
|---|---:|---:|
| `Global_WaveStrength` | 1.0 | 0.0 |
| `Main_Amplitude` | 300 | 0 |
| `Secondary_Amplitude` | 100 | 0 |
| `Detail_Amplitude` | 0 | 0 |
| `Foam_DetailStrength` | 0.55 | 0 |
| `Foam_BaseOpacity` | 0.72 | 0 |
| `Fresnel_Strength` | 0.06 | 0.02 |
| `QUALITY_UseGeometricWaves` | True | False |

把它赋给 `Ocean_Far`。

`QUALITY_UseGeometricWaves` 是 Static Switch：True 分支输出第 03 部分的 WaveHeight、WaveNormal 和 WPO；False 分支输出高度 0、法线 `(0,0,1)`、WPO `(0,0,0)`。这样 Far 不会为不可见的波浪继续计算两次三角函数。

远景不是缩小版近景。当前 Far 网格只需要保持色调并接住距离雾，不需要真实起伏。

## 2. 处理近远景接缝

近景和远景几何重叠时可能 Z-Fight。选择以下一种方案：

### 方案 A：高度错开

- 近景 Z = `-14610`。
- 远景 Z = `-14640`。
- 两者 Location X/Y 都为 `(13970, 17200)`。
- 依靠深色和雾隐藏高度差。

这是第一版推荐方案。

### 方案 B：制作带中心孔的远景环

使用 Modeling Mode 将远景网格中心区域删除，形成环形网格。内孔略小于 Near 的 2 km 范围，允许两者重叠 50–100 m。

这种方案更干净，但制作与修改成本略高。

## 3. 使用距离统一远景颜色

在主材质中添加可选的距离雾化颜色：

参数：

| 参数 | 默认值 |
|---|---:|
| `DistanceColor_Start` | 50000 |
| `DistanceColor_End` | 500000 |
| `DistanceColor_Strength` | 0.65 |
| `Color_Horizon` | `#07151C` |

计算：

```text
Distance01 = Saturate(
    (CameraDistance - Start)
    / (End - Start)
)

DistanceBlend = Distance01 × DistanceColor_Strength
ColorWithDistance = Lerp(OceanWithFoam, Color_Horizon, DistanceBlend)
```

这样可在真正进入 Height Fog 之前先压低远景的色彩和泡沫差异。

## 4. 配置 Exponential Height Fog

在关卡中放置或找到 `ExponentialHeightFog`。

建议起点，而不是固定答案：

| 设置 | 建议起点 |
|---|---:|
| Fog Density | 0.006–0.020 |
| Fog Height Falloff | 0.15–0.30 |
| Start Distance | 20000–50000 cm |
| Fog Max Opacity | 0.75–0.95 |
| Volumetric Fog | 开启后按性能评估 |

Fog Inscattering Color 使用非常深的蓝灰，不要使用明亮天空蓝。

调节顺序：

1. 先固定玩家主镜头。
2. 提高 Fog Density，直到海天线开始消失。
3. 用 Start Distance 保住近景海面清晰度。
4. 用 Height Falloff 避免宫殿主体完全被吞没。
5. 最后才调 Volumetric Fog。

## 5. 主光方向

Directional Light 应从侧后方或斜侧方照射，使宫殿获得剪影层次，同时在海面产生有限高光。

建议：

- 光源角度低于常规正午场景；
- 不直接从相机方向照射；
- 色温偏冷或中性；
- 强度以宫殿可读性为准，不以海面高光为准。

材质中的 `GraphicLightDirection` 可以大致跟随真实主光，但不必完全相同。

## 6. Sky Light

Sky Light 负责让深色海面保留最低限度层次。

检查：

- 宫殿阴影中仍能分辨主要体块；
- 海面深色区域不是 RGB 全接近 0；
- 不因 Sky Light 太强而失去黑色负空间；
- 若使用实时捕获，测试动态变化是否造成海面闪烁。

不要为了看清海面而过度提高 Sky Light。优先调整 `Color_Deep`、曝光和极弱 Fresnel。

## 7. 反射策略

第一版不建议使用清晰 Planar Reflection。

推荐：

- 使用 Lumen／环境反射提供模糊响应；
- 保持 Roughness 0.3–0.55；
- 不让宫殿在海面形成完整镜像；
- 必要时用局部暗色光或 Decal 表现宫殿下方污染，而不是依赖真实倒影。

## 8. 宫殿下方的视觉锚点

为避免宫殿像与海面无关地漂浮，可加入非常克制的局部关系：

- 海面下方一圈较深的压暗；
- 熔炉区域极弱暗红反射；
- 垂直管线下方少量密集泡沫；
- 低频雾柱或蒸汽。

这些效果应局限在宫殿投影附近，不能变成整片红海。

## 9. 固定构图截图

至少保存三个调试镜头：

1. 玩家常规高度，宫殿为主体。
2. 接近海面，检查波浪和泡沫。
3. 高位俯视，检查重复纹理和覆盖率。

每次调整雾、颜色或波浪后，用同样镜头比较，不要只凭实时漫游感觉。

## 10. 本部分验收

- [ ] 近景与远景没有明显 Z-Fighting。
- [ ] 玩家主镜头看不到近景方形边缘。
- [ ] 远景高频波浪和 Detail 泡沫已关闭。
- [ ] 海天线被深色雾软化或隐藏。
- [ ] 宫殿轮廓比海面更醒目。
- [ ] 没有清晰、写实的宫殿镜像。
- [ ] 三个固定测试镜头已经建立并截图。

## 常见错误

### 远景像一张完全静止的地板

当前 Far 的实际顶点间距过大，不要恢复 WPO。通过距离颜色、轻微 Fresnel 和雾隐藏静止感；需要更丰富的远景时，增加低频像素颜色变化，而不是移动 Far 顶点。

### 海天线仍然是一条亮线

降低远景 Fresnel，提高距离颜色混合，并让 Fog Inscattering Color 接近 `Color_Horizon`。

### 雾隐藏了整个宫殿

提高 Fog Start Distance，调整 Height Falloff，并检查宫殿是否被错误放在雾密度最高区域。
