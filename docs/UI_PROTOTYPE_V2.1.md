# Osaider Cockpit UI Prototype v2.1

## 核心调整

- 中央观察窗扩大为画面的绝对主体，约占整屏宽度的 70–75%、高度的 78–82%。
- 左侧录音档案屏与右侧物品分析器收窄并贴边，底部仪表条压缩为浅层信息带，避免遮挡建筑。
- 建筑继续采用鲜明的低多边形造型，并通过黑色宇宙背景强化尺度感。

## 复古未来主义仪表语言

- 外壳：暖灰、奶油白、鼠尾草绿。
- 强调色：橙红、青色、黄色与绿色指示灯。
- 显示器：绿色荧光 CRT、圆形雷达/示波器、简化数字读数。
- 控件：大尺寸实体按键、旋钮、拨杆和彩色灯阵；保持图形化和非写实表达。
- 表面：仅保留轻度纸张颗粒、油墨磨损与扫描线，不使用厚重污渍或照片级材质。

## 交互模块

- 左屏：`ARCHIVE RECORD`、频道和时码、录音波形、`PLAY / PAUSE`。
- 右屏：三个纵向物品槽，每个槽位拥有独立指示灯与连接线路。
- 三个物品全部放入后，`READY` 灯进入闪烁状态，`3 / 3 INPUT` 显示完成。
- 玩家点击 `ANALYZE` 后进入自动骰子检定。
