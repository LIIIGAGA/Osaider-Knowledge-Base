# OSAIDER UI PROTOTYPE V1.5

Reference: `docs/assets/osaider-gameplay-ui-preview-v1.5-print-texture.png`

## Print Texture Layer

- Narrative surface: cool-grey paper fibre at very low opacity
- Typewriter copy: slight ink-density variation with crisp glyph edges
- Red wedges: sparse dry-ink pinholes
- Frames: a few deliberate missing segments and minor registration offset
- Cyan information: nearly clean, with only faint screen-print grain
- Cursor and interaction nodes: fully clean digital shapes

## Limits

- Texture must not be applied to the 3D game scene.
- Do not use yellow paper, stains, folds or torn edges.
- Texture should disappear visually at a distance and become noticeable only at close range.
- Keep all body copy at full gameplay readability.
