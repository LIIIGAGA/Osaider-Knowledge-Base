# OSAIDER UI PROTOTYPE V1.4

Reference: `docs/assets/osaider-gameplay-ui-preview-v1.4-typewriter.png`

## Typography System

- Narrative body: clean old mechanical typewriter monospaced serif
- Secondary labels: compact bold typewriter monospace
- Channel and slot numbers: tabular monospaced numerals
- Primary actions: Constructivist condensed sans serif
- Game title: Constructivist display face

## Usage Boundary

The typewriter face communicates records, testimony and bureaucracy. It should not be used for every interaction element.

- Use it for narrative text, item names, record metadata and system labels.
- Keep primary buttons and major navigation in the condensed Constructivist face.
- Do not add ink distress, paper texture or intentionally broken characters.
- Increase line spacing for long English passages.
- Use a separate CJK typeface when Chinese localization is required; do not force Latin typewriter glyph styling onto Chinese text.
