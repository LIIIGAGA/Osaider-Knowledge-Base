# OSAIDER UI PROTOTYPE V1.2

Reference: `docs/assets/osaider-ui-prototype-v1.2.png`

V1.2 redesigns the three-item submission module around a circular analysis core.

## Submission Flow

`Slot 01 + Slot 02 + Slot 03 -> Analysis Core -> Result -> Submit`

## Analysis Core

- Three explicit incoming connection points
- Concentric rings and radial ticks
- Red and cyan arcs showing the combined hidden balance
- Central activation node
- One outgoing result path

## Interaction States

1. Empty slots show only a plus sign and inactive socket.
2. Adding an item lights its connection path toward the core.
3. Filling all three slots expands and activates the circular core.
4. Analysis animates the red and cyan arcs around the centre.
5. The result node activates, enabling the Submit button.

The ring is an abstract analytical instrument. It must not be presented as a literal map, radar or physical machine.
