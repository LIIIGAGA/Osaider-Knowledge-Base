# 第 01 部分：项目备份与素材准备

## 本部分目标

完成这一部分后：

- 旧的 Submission 功能有可恢复备份；
- 两张 UI 素材已正确导入 UE；
- 外圈可以围绕正中心旋转且不会被裁切；
- 内层线稿保持透明；
- 后续文档使用的命名已经确定。

## 1. 备份当前可运行版本

在 Content Browser 中找到：

- `BP_CoreDevice`
- `BP_NoCharacterPlayerController`
- `WBP_SubmissionPanel`
- `WBP_InventoryPanel`
- 常驻 HUD Widget

建议做法：

1. 在项目外记录当前关卡名称和测试入口。
2. 如果使用 Git，先提交当前能够运行的版本。
3. 如果暂时不用 Git，复制最关键的 Blueprint，名称加 `_Backup_PreSubmissionV2`。
4. 不要直接删除旧 Enter 鉴定逻辑；先把它断开并加 Comment：

   `Legacy Enter Dice Check — keep until V2 passes testing`

5. 记录旧流程中真正执行模块 Reveal 的函数或事件名称。

## 2. 创建 UI 资源目录

建议在 UE Content Browser 中创建：

```text
Content/UI/SubmissionV2/
├─ Textures/
├─ Widgets/
├─ Animations/
└─ Input/
```

如果你的项目已经有统一 UI 目录，可以放进现有目录，但要保持命名清晰。

## 3. 导入两张透明素材

导入以下文件：

### 旋转外圈

`WBP_SubmissionPanel_v2_OuterRing_RotationSquare.png`

路径：

`Design/UI_Assets/SubmissionPanel/SplitFromV2/`

特征：

- 941 × 941；
- 正方形；
- 透明背景；
- 专门用于旋转。

建议导入后重命名：

`T_UI_Submission_OuterRing_Rotation`

### 内层三圆与三角线稿

`WBP_SubmissionPanel_v2_InnerThreeSlots_Triangle_LineArt_NoBlackEdge.png`

特征：

- 1672 × 941；
- 三个槽位、三角形、中央按钮线稿；
- 圆内与黑边均为透明。

建议重命名：

`T_UI_Submission_InnerLineArt`

## 4. 设置纹理属性

分别打开两张 Texture Asset，在 Details 中设置：

1. `Texture Group`：UI。
2. `Compression Settings`：`UserInterface2D (RGBA)`。
3. `Mip Gen Settings`：如果 UI 始终接近原尺寸，可使用 `NoMipmaps`；如果会大范围缩放，先保留默认并实际测试。
4. `sRGB`：保持开启，除非你已经用材质单独处理颜色。
5. `Never Stream`：UI 常驻且体积可接受时可以开启。
6. 检查 Alpha 通道，透明区不应出现黑底方块。
7. Save。

## 5. 单独测试外圈旋转

先创建临时 Widget：`WBP_Test_SubmissionRing`。

Designer：

1. 添加 Canvas Panel。
2. 添加一个 Image。
3. Brush 使用 `T_UI_Submission_OuterRing_Rotation`。
4. Size 设置为 `941 × 941` 或等比缩小。
5. Alignment 设置为 `0.5, 0.5`。
6. Anchor 设在屏幕中心。
7. Render Transform Pivot 设置为 `0.5, 0.5`。

创建一个 2 秒测试动画：

- 0 秒：Angle 0。
- 2 秒：Angle 360。

运行检查：

- 圆不能上下或左右晃动；
- 旋转时不能被矩形边界裁切；
- 圆心必须保持固定。

如果旋转时被裁切：

1. 检查父控件的 `Clipping`。
2. 不要设置成 `Clip to Bounds`。
3. 检查 Image 是否真的使用正方形素材。
4. 检查 Pivot 是否为 `0.5, 0.5`。

## 6. 确认当前物品数据类型

打开 `BP_CoreDevice`，找到 `SubmittedItems`。

记录它的元素类型，例如可能是：

- 某个 Item Struct；
- Object Reference；
- Data Table Row Handle；
- 自定义 Item Data Object。

后续文档统一把这个类型称为：

`ItemDataType`

不要为了跟文档一致而创建一个新 Struct。所有新变量必须使用 `SubmittedItems` 当前的元素类型。
