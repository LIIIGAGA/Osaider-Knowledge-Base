# OSAIDER UI PROTOTYPE V1.1

Reference: `docs/assets/osaider-ui-prototype-v1.1.png`

V1.1 retains the minimal low-poly signal-frame language of V1.0 and adds abstract Soviet nuclear control-room information patterns.

## Added Motifs

- Circular status-light matrices
- Orthogonal system flow lines
- Numbered channels and zones
- Small repeated switch-cell rhythms
- Minimal dial arcs and instrument ticks
- Muted mustard status bands used as a minor accent
- Red, cyan, white and inactive-grey indicator states

## Component Application

- Narrative rail: vertical channel selector and status lights
- Inventory: numbered item channels
- Submission: three items connected as a process-flow diagram
- Item found: miniature signal path and status nodes
- Dice check: circular state matrix and vertical result lamps
- Pause: sparse system control-bank grid
- Cursor: subtle instrument ticks around the existing split diamond

## Style Boundary

The control-room reference is expressed through information density and topology only. Do not add realistic knobs, gauges, metal consoles, wear, grime or historic emblems.
